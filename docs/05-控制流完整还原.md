### 3.1 三种 x87 标志掩码 —— 完整配对统计

### 4.1 核心规则：区间重叠判定

```c
// 设相邻两段 a（前）、b（后）：
//   a.low  = a->field_0C ;  a.high = a->field_10
//   b.low  = b->field_0C ;  b.high = b->field_10
//
// 【判定一】a.low  vs  b.high   （掩码 41h / 1）
//   a.low <  b.high  →  区间在低端重叠
//   a.low >  b.high  →  完全不重叠（b 整体高于 a）→ 无脑买点
//
// 【判定二】a.high vs  b.low    （掩码 1 / 41h）
//   a.high > b.low   →  区间在高端重叠
//   a.high < b.low   →  完全不重叠（b 整体低于 a）→ 无脑卖点
```

**「无脑」的严格数学定义**（本批最终确定）：

```
两段区间 [low_a, high_a] 与 [low_b, high_b] 不重叠
        ⟺   high_a < low_b   或   high_b < low_a
        ⟺   满足其一即标记买卖点
```

这比第四批「`≠` 即标记」的表述**更精确** —— 实际是**严格不等重叠**，用 `>`/`<` 判定，而非仅判 `≠`。

### 4.2 `+0A0h` 跨对象比较 —— 印证 0xA0 步长

表中 `+0A0h vs +94h`、`+0A0h vs +78h` 等组合证明引擎会**以当前对象地址 ±0xA0 直接访问相邻对象**（无需查表），这正是「邻近区间」的实现方式。


这与缠论「**买点出现在底分型右侧、卖点出现在顶分型左侧**」的结构完全一致 —— **买卖对称，各取分型的另一侧顶点**。

### 8.2 主判定伪代码

```c
void wn_mr_engine(LevelObj* arr, int n) {
    for (int i = 0; i + 1 < n; i++) {
        LevelObj* a = &arr[i];
        LevelObj* b = &arr[i + 1];              // 邻点：地址 +0xA0

        // ── 卖出判定（高端不重叠）──
        if (a->low > b->high) {                 // test ah,41h + jne
            if (a->direction == 0) {            // +0x20 未定向
                a->status = 4; a->price = a->low;
                // 后续: status=5 (卖出价), status=6 (止盈价)
            }
        }
        // ── 买入判定（低端不重叠）──
        else if (a->low < b->high) {            // test ah,1 + jne
            if (b->direction == 0) {
                b->status = 1; b->price = b->high;
                // 后续: status=2 (买入价), status=3 (止损价)
            }
        }
    }
}
```

## 九、遗留问题（诚实列出）

1. **4 个实例对应的 4 个容器具体是什么** —— 静态上只能确认它们是 4 个独立的迭代器槽位；需动态调试观察 `[esp+43Ch]`（容器基址）在 4 组中的实际值，才能确定是「笔/线段/走势类型/自定义」还是「4 个时间窗」。
2. **`sub_1003F0D0` / `sub_1003D720` 未逐条反汇编** —— 已确认功能（迭代器构造 / `++`），但内部边界检查细节未展开。
3. **`+0x64` / `+0x78` / `+0x80h` / `+0x94h` / `+0x98h` 栈缓存变量来源** —— 部分为局部极值缓存，需继续跟踪。
4. **`0x1005b2be: mov [esp+90h],1`** —— 栈变量写入，与结构体状态码无关，需单独定位其用途。
5. **动态验证未做** —— 建议 x64dbg 在 `0x1005a1fa` 下断点，记录 `esi`（对象地址）、`[esi+0Ch]`、`[esi+10h]`、`[esi+20h]`、`[esp+43Ch]`。
