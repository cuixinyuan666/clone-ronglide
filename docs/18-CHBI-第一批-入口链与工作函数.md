### 1.1 `sub_1001c110`（28 条指令）= shared_ptr 包装器

```
sub_1001c110(T, out):
    out = {T, 0}                      ; 构造 pair {T指针, refcount槽}
    push out; call 0x1001c940         ; → 建控制块
    return out
```
`0x1001c940`（39 条）：原子引用计数操作 + 调 `0x1001d9f0`（`new(0x10)` 控制块
`{vtable=0x1006f750, refs=1,1, [0xc]=参数}`）+ `0x1001e780`（空函数）。

> 即：**0x1001c110 不是算法**，而是 MSVC `shared_ptr` 家族桩（含 `lock xadd` 原子序列）。
> 归属证明：调用者 = `ChBi`(1000f692) + `NChBi`(10012b37) —— 同为「笔」族入口。

## 二、工作函数 `sub_1002c1d0` 概览

### 2.1 签名与序言（实测）

```
sub_1002c1d0(ctx, count, inArray, outArray, obj4)
    if (count <= 0) return;  if (outArray == NULL) return;
    bufA = new[](count * 4);              ; 0x1006b34a (operator new[])
    bufB = new[](count * 4);
```

### 2.2 首段：输入 double 数组 → float 缓冲（逐 bar）

```asm
1002c24d  fld   qword ptr [edx + eax]     ; 源数组按 8 字节步长读 (double)
1002c253  fstp  dword ptr [esi + ecx - 4]; 写入 bufA (float)
1002c25d  fld   qword ptr [eax - 8]       ; 同一元素二读
1002c260  fstp  dword ptr [ecx - 4]       ; 写入 bufB (float)
1002c263  fst   qword ptr [edi + eax - 8] ; 另存一份 double 到目标
```

> 结论：**输入为 double 数组**（公式引擎统一用 double 传递价格），函数内部降为 float 计算。

### 2.4 数据结构线索

- `lea esi, [ebx + 0xa0]` ×2 → 遍历 **0xA0 步长**容器（级别对象 m[0] 或同布局容器）。
- 全程 **无 fcompp** —— 浮点判定下放到 `0x1003f150`/`0x1004b1e0` 等子调用之内（第二批展开）。
- 与 CHDUAN 共用 `0x1003eba0`（m[2] 预处理）→ **m[2] 是笔/线段两级计算的中转容器**。

## 四、与既有结论的接合

1. **授权**：CHBI 的 EA62 门只在 `P==51` 触发（docs/15）——「老笔/新笔自由、分型笔收费」。
2. **数据流**：CHBI 通过 `0x1002c1d0` 把 **W** 的 m[0]/m[2] 等容器的状态构建/刷新，
   随后 CHDUAN 的准备函数（`0x10053540`）直接消费同一批容器 → 全链闭环成立。
3. **复用层**：`0x1003eba0`（m[2] 预处理）、`0x1003ef00`（方向标注）、`0x1003f150`（快照）
   构成「笔/段」两级共用的工具集。
