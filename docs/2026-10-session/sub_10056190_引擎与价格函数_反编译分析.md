## 四、触发条件还原

每个买卖块入口都有一个**双条件门禁**：

### 4.1 条件一：价格不等判定（`fcompp` + `test ah,5`）

以买入块为例（`0x1005a174`–`0x1005a185`）：

```asm
0x1005a178: fld dword ptr [esi+0Ch]      ; ST0 = LOW_a
0x1005a17b: fld dword ptr [eax+10h]      ; ST0 = HIGH_b, ST1 = LOW_a
0x1005a17e: fcompp                       ; 比较 HIGH_b ? LOW_a
0x1005a180: fnstsw ax
0x1005a182: test ah,5                    ; 检测 C0=0,C2=1 (≠)
0x1005a185: jnp 1005A1B5h                ; 不相等 → 进入买入块
```

**x87 标志位解码**（`fnstsw ax` 后 AH 的 C0/C2/C3 位）：

| `test ah, 5` | 含义 | 动作 |
| --- | --- | --- |
| `ah & 5 == 0`（`jp` 成立） | 相等 | 跳过块 |
| `ah & 5 == 5`（`jnp` 成立） | **不相等** | **进入买入块** |

对照 `sub_100560d0`（极小值搜索）使用 `test ah,41h` + `jne`（相等则跳过 → 找 `<`），可确认：
- **`test ah,5` + `jnp` = 判定「≠」（不等）**

### 4.2 条件二：方向过滤（`+0x20` 字段）

```asm
0x1005a18e: cmp dword ptr [esi+20h],1
0x1005a192: je near 10056610h            ; 若 方向==1(已上涨) → 跳过
0x1005a19f: cmp dword ptr [esi+20h],0FFFFFFFFh
0x1005a1a3: je near 10056610h            ; 若 方向==-1(已下跌) → 跳过
```

**逻辑**：若该级别对象已被标记方向（`±1`），则跳过；仅处理方向未定（`0`）的对象。

## 五、极值搜索子函数（关键数学）

`sub_10056010` 与 `sub_100560d0` 是引擎的**唯一「数学」部分** —— **一维数组极值索引搜索**。

### 5.1 `sub_10056010` —— 求最大值索引（argmax，严格大于才更新）

比较序列（`0x10056032`）为 `fld A; fld B; fcompp` → 计算 **B − A**（B=`best`，A=`arr[k]`），`test ah,5` + `jp` 决定是否跳过更新。

**x87 标志位精确解码**（已用脚本逐例验证）：

| B−A 结果 | C0 | C2 | C3 | AH | `ah&5` | `jp` 动作 |
| --- | --- | --- | --- | --- | --- | --- |
| B > A（best 较大） | 0 | 0 | 0 | `0x00` | `0x00` | **跳（跳过更新）** |
| B < A（best 较小） | 1 | 0 | 0 | `0x01` | `0x01` | 不跳（**更新**） |
| B = A | 0 | 0 | 1 | `0x40` | `0x00` | **跳（跳过更新）** |
| NaN | 0 | 1 | 0 | `0x04` | `0x04` | 不跳（更新） |

```c
// sub_10056010(float* arr, int n)  → argmax (1-based)
float best = arr[0];  int idx = 1;
for (int k = 1; k < n; k++) {
    if (!(best >= arr[k])) {      // 即 best < arr[k]  ← 严格大于才更新
        best = arr[k];  idx = k + 1;
    }
}
return idx;   // 最大值【首次】出现位置（NaN 视为可更新）
```

汇编特征：4 路循环展开（`add ecx,4` / `add edx,10h`），`lea esi,[ecx+N]` 更新索引。

### 5.2 `sub_100560d0` —— 求最小值索引（argmin，大于等于即更新）

结构完全对称，比较条件换成 `test ah,41h`（C0｜C3）+ `jne`：

| B−A 结果 | C0 | C2 | C3 | AH | `ah&41` | `jne` 动作 |
| --- | --- | --- | --- | --- | --- | --- |
| B > A | 0 | 0 | 0 | `0x00` | `0x00` | 不跳（**更新**） |
| B < A | 1 | 0 | 0 | `0x01` | `0x01` | 跳（跳过更新） |
| B = A | 0 | 0 | 1 | `0x40` | `0x40` | 跳（跳过更新） |
| NaN | 0 | 1 | 0 | `0x04` | `0x00` | 不跳（更新） |

```c
// sub_100560d0(float* arr, int n)  → argmin (1-based)
float best = arr[0];  int idx = 1;
for (int k = 1; k < n; k++) {
    if (best >= arr[k]) {         // ← 大于等于即更新
        best = arr[k];  idx = k + 1;
    }
}
return idx;   // 最小值【最后】出现位置
```

### 5.3 两者的关键差异（刻意设计）

| 函数 | 更新条件 | 等值时行为 | 结果语义 |
| --- | --- | --- | --- |
| `sub_10056010` | `best < arr[k]`（严格） | 保留靠前 | **max 的首次位置** |
| `sub_100560d0` | `best >= arr[k]`（非严格） | 取靠后 | **min 的最后位置** |

**用途**：这两个函数负责在线段/笔的端点数组上定位**最高点与最低点**，是「区间套」「中枢区间」判定的数学基础。二者的严格性差异（max 取首、min 取尾）会直接影响边界重叠判定，是复刻时必须保持的细节。

## 六、`sub_1003a960`（WNMRPRINEW）逐段反编译

此函数极简，仅做**数组搬运**：

```c
// 签名: int sub_1003a960(void* this, int count, double* out, void* ctx)
// 注: ret 4 —— 只有 1 个栈参数（与 WNMRNEW 的 ret 0Ch 不同）
int __stdcall sub_1003a960(void* objList /*eax*/, void* ctx /*edx*/, int count /*ecx*/, double* out /*[esp+34h]*/) {

    if (ctx == NULL)              return -1;          // 0x1003a969
    if (count > 0)                                    // 0x1003a96f
        memset(out, 0, count*8);                      // rep stosd 清零

    if (!ctx->Authorize(0xEA63))  return -1;          // 0x1003a98c 授权门禁

    void* first = sub_1003f150(objList);              // 取首元素

    int i = 0;
    for (obj = first; obj != last; obj += 0xA0) {     // 步长 160
        int k = obj->index - 1;                        // 0x1003a9fb: sub esi,1
        out[k] = (double)obj->field_94;                // ★ 0x1003aa0e: fld [ebp+94h]
        i++;
    }
    return 1;
}
```

**关键点**：
- 读 `+0x94`（float）→ 转 double 写入 `out[index-1]`
- `+0x94` 正是 `sub_10056190` 写入的「实际价格」
- **结论**：`VAR6:=WNMRPRINEW;` 得到的是各买卖点的**原始价格值**，而非按比例算出的值

## 九、核心判定规则（最终可执行表述）

### 无脑买入（状态码 2）
```
条件：当前区间 LOW_a ≠ 邻近区间 HIGH_b   （fcompp 不等）
      且 该点方向未标记 (+20h == 0)
动作：该点 +90h = 2，+94h = 该区间 HIGH (+10h)
```

### 无脑卖出（状态码 5）
```
条件：对称条件（HIGH_a ≠ LOW_b，fcompp 不等）
      且 该点方向未标记 (+20h == 0)
动作：该点 +90h = 5，+94h = 该区间 LOW (+0Ch)
```

### 止损（3）/ 止盈（6）
```
分别取同一区间的 HIGH / LOW，作为风险控制参考位
```

**「无脑」的完整含义**：只要相邻两段的价格区间**不重叠**（`≠`），即在区间边界直接标记买/卖点，不要求中枢确认、不要求背驰、不要求 MACD 验证 —— 这就是「无脑」的算法本质。
