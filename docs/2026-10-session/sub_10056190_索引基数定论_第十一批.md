## 二、0x28 bar 的填充链路(完整)

```
W->m[4]  (vector<0x28>, 数据 +0x44/+0x48)
   │
   ├─ _Allocate<0x28>        sub_1006b160   （cmp eax,0x28；lea edx,[ecx+ecx*4]×2×2×2 = ×40）
   ├─ _Reallocate<0x28>      sub_1006ad60   （写 vector 头 +4/+8/+0xC）
   ├─ push_back              sub_1006a9e0
   ├─ emplace_back           sub_1006a720   （÷40 判容量；调 _Uninitialized_copy_n）
   └─ _Uninitialized_copy_n  sub_1006b1f0   （mov ecx,0xA; rep movsd —— 40 字节/元素）
```

> **重要**:bar 不是逐字段构造,而是**整体拷贝**。
> 这印证批 8 的候选解释 (b)「字段由批量拷贝带入」。

## 三、🔑 bar 的真正写入点:栈上临时量

`emplace_back`(`sub_1006a720`)的调用者先在**栈上**填一个 0x28 字节的临时 bar,再把地址传给 `eax`:

```asm
;; sub_1003e410 @ 0x1003e590 附近
0x1003e592: mov dword ptr [esp + 0x38], eax     ; temp+0x00 = eax
0x1003e596: mov dword ptr [esp + 0x3c], esi     ; temp+0x04 = esi
0x1003e5a6: fld dword ptr [edi + 0x0c]         ; 读级别对象 +0x0C（LOW）
0x1003e5ac: fstp dword ptr [esp + 0x44]         ; temp+0x0C = LOW
0x1003e5b0: mov eax, dword ptr [esp + 0x14]     ; ★ eax = 索引
0x1003e5b4: mov dword ptr [esp + 0x40], eax     ; ★★ temp+0x08 = 索引
0x1003e5c0: fld dword ptr [ebp + 0x10]         ; 读级别对象 +0x10（HIGH）
0x1003e5c7: lea eax, [esp + 0x38]              ; ★ eax = &temp bar
0x1003e5cb: fstp dword ptr [esp + 0x48]         ; temp+0x10 = HIGH
0x1003e5cf: call 0x1006a720                     ; emplace_back(vector, &temp)
```

**临时基址 = `[esp+0x38]`,故 `+0x08` 对应 `[esp+0x40]`。** ✓

## 五、🎯 基数定论

### 5.1 `+0x00` 是 **1 基**

```asm
0x1003e4f6: mov dword ptr [esp + 0x10], esi    ; [esp+0x10] = 0   （esi=0）
0x1003e57c: mov eax, dword ptr [esp + 0x10]
0x1003e580: add eax, 1                          ; ★ +1
0x1003e586: mov dword ptr [esp + 0x10], eax
0x1003e592: mov dword ptr [esp + 0x38], eax     ; temp+0x00 = [esp+0x10]+1 → 1,2,3,…
```

**`+0x00` 取值为 1, 2, 3, …** ✓ 与批 4「`+0x00` 为 1 基序号」一致。

### 5.2 `+0x08` 是 **0 基**

`[esp+0x14]` 的初始化与更新:

```asm
;; 初始化（按 vector 是否为空分支）
0x1003e4cc: xor esi, esi
0x1003e4ce: cmp eax, esi                        ; eax = W->m[0]._Myfirst
0x1003e4d4: jne 0x1003e4dc
0x1003e4d6: mov dword ptr [esp + 0x14], esi     ; ★ 空 vector → 索引 = 0
0x1003e4da: jmp 0x1003e4f6
0x1003e4dc: mov ecx, dword ptr [edi + 8]        ; _Mylast
0x1003e4e1: mov eax, 0x66666667
0x1003e4e8: sar edx, 6                           ; ÷160 → N（元素个数）
0x1003e4f2: mov dword ptr [esp + 0x14], eax      ; ★ 否则 → 索引 = N（哨兵）

;; 循环体尾部（推进）
0x1003e510: mov esi, 2                           ; ★ 元素下标从 2 起
0x1003e502: call 0x1003f0d0                      ; begin() + 2
0x1003e696: add esi, 1                           ; i++
0x1003e69c: mov dword ptr [esp + 0x18], esi
0x1003e6a8: add edi, 0xa0                         ; 下一级别对象
0x1003e6ae: cmp esi, dword ptr [esp + 0x24]      ; 界 = N-1
0x1003e6b2: jl 0x1003e528

;; 每次构造后把 [esp+0x14] 更新为当前下标
0x1003e5d8: mov dword ptr [esp + 0x14], edx      ; edx = [esp+0x18] = i
0x1003e67f: mov dword ptr [esp + 0x14], ecx      ; ecx = [esp+0x18] = i
0x1003e68c: mov dword ptr [esp + 0x14], esi      ; esi = i
```

**取值序列**:

| 情形 | `+0x08` 取值 |
|---|---|
| `W->m[0]` 为空 | **0** |
| 非空但无前驱 | **N**（哨兵 = 元素个数,即"末元素之后") |
| 循环第 k 次（元素下标 i = 2,3,…） | **i − 1**（0 基下标） |

**关键推理**:
1. **空 vector 时索引 = 0** —— 若是 1 基,空时应为 1 或"无";取 0 直接表明 **0 基**。
2. 正常路径取值 `i − 1`,其中 `i` 是 `begin() + i` 得到的**0 基元素下标**。
3. 哨兵值 `N`(元素个数)= 合法的"越界"值,仅在 0 基语义下才自洽。

> ### ✅ **定论:`+0x08` 是 0 基索引。**

### 5.3 与 `sub_1003f0d0` 的自洽

```c
/* 构造侧 */ bar->+0x08 = k;                       /* 0 基 */
/* 消费侧 */ result = W->m[0].begin() + n;         /* n 原样使用,无 ±1 */
```

**两侧基数一致 → `begin() + n` 精确命中目标元素,不存在 off-by-one。**
批 8 提出的三个候选假设中,**假设 B(0 基)成立**,假设 A(哨兵元素)、C(越界被断言掩盖)不成立。

## 七、最终算法表述(可执行)

```c
/* 级别对象 vector：W->m[0]（0xA0 元素，0 基下标） */
/* 输入 bar  vector：W->m[4]（0x28 元素）              */

/* ① 建 bar：+0x08 = 该 bar 对应的级别对象 0 基下标（无前驱时为 N，哨兵） */
bar->idx00 = ++serial;          /* 1 基序号 */
bar->idx08 = prev_element_pos;  /* 0 基下标，或 N（哨兵） */
bar->low   = level->low;        /* 级别对象 +0x0C */
bar->high  = level->high;       /* 级别对象 +0x10 */

/* ② 引擎取 9 个连续 bar 建迭代器窗口 block[0..8] */
for (i = 0; i < 9; i++)
    block[i] = { &W->m[4], W->m[4].begin() + 1 + i };   /* 从第 2 个 bar 起 */

/* ③ 判定（以 block[5] 为例） */
n = block[5]->+0x08;                       /* 0 基索引 */
target = W->m[0].begin() + n;              /* ★ 精确命中，无需 ±1 */
if (block[5]->+0x10 < target->low) {       /* 区间不重叠 */
    target->status = 1; target->price = target->high;
}
```
