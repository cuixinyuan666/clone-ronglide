## 三、关键子函数反编译

### 3.1 `sub_10060aa0` —— 状态位打标（最重要）

这是**信号判定的核心**。它遍历所有级别对象（步长 0xA0），比较数值与阈值，向 `+0x8C` 写入 `0 / 1 / -1`：

```c
// sub_10060aa0(容器edi, count[esp+18h], temp[] [esp+1Ch])
void sub_10060aa0(void* edi, int n, float* arr) {
    // 阶段1：清空所有对象 +0x8C = 0
    for (obj = first; obj != last; obj += 0xA0)
        obj->field_8C = 0;

    // 阶段2：逐元素比较
    for (int i = 0; i < n; i++) {
        float v = arr[i];
        if (v == 1.0f) {              // fld1 / fcomp  →  等于 1.0
            // 找到一个 obj.index == (i-1) 的对象
            for (obj = first; obj != last; obj += 0xA0) {
                if (obj->field_00 == i - 1) {
                    if (arr[obj->field_00] == 1.0f)   // 再次校验
                        obj->field_8C = 1;            // ★ 标记为 +1
                    else
                        obj->field_8C = -1;           // ★ 标记为 -1
                    break;
                }
            }
        }
        else if (v == -1.0f) {       // fcomp [1006FC50h] = -1.0f
            // 该分支被跳转到 0x10060BD9（跳过打标）
        }
        // 其他值：不打标
    }
}
```

**常量证据**（`.rdata` 实测）：
| 地址 | 原始字节 | 浮点值 | 用途 |
| --- | --- | --- | --- |
| `0x1006FC50` | `000080BF` | **-1.0** | 比较基准（底分型/下降标志） |
| `0x1006FC4C` | `6666EE3F` | **1.8625** | 邻近阈值 |
| `0x1006FC54` | `00000000` | 0.0 | 清零基准 |
| `0x1006FC60` | `00000040` | 2.0 | — |
| `0x1006FC64` | `000000C0` | -2.0 | — |
| `0x1006FCF0` | `77BE7F3F` | 0.999 | 近似等于容差 |
| `0x1006FCF4` | `17B7D138` | 1e-4 | 浮点 epsilon |
| `0x1006FCFC` | `CEF7EF3F` | 1.87475 | 比率类常量 |
| `0x1006FD04` | `E2361A3F` | 0.6024 | 比率类常量 |
| `0x1006FD0C` | `9999B93F` | 1.45 | 比率类常量 |

**语义推论**：
- 输入数组 `arr[]` 是级别对象的**分型序列**（来自 `CHDUAN`，取值 ±1）。
- 当 `arr[i] == 1.0`（顶分型）时，回查 `index == i-1` 的对象：若其值也为 1 → 标记 `+1`；否则标记 `-1`。
- 该 `+0x8C` 标志位被下游 `sub_100616b0` 用作**过滤条件**（`cmp [edi+8Ch], 1`）。

> 浮点比较用 `fcomp` + `fnstsw ax` + `test ah,44h`（C0=0 且 C3=0 → 相等），是 x87 的标准等值判定模式。

### 3.2 `sub_100616b0` —— 序列归并/裁剪

```asm
0x10061785: mov eax,1
0x1006178a: cmp [edi+8Ch],eax        ; ★ 读取 +0x8C 标志
0x10061790: jne near 1006183Eh       ; 标志 != 1 → 跳过
0x10061796: cmp dword ptr [esp+14h],0
...
```

该函数遍历容器，**仅保留 `field_8C == 1` 的对象**，并做重采样（`sub_1006B050` 内存移动）。它将打标结果规整为可序列化的级别序列。

### 3.3 `sub_10056190` —— 主计算引擎（8173 条指令）

栈帧 `0x428` 字节，是缠论走势计算的核心。开头即对容器 `+0x44` / `+0x48` 做**元素计数**：

```asm
0x10056237: mov eax,[ebx+44h]        ; 起始索引
0x10056265: mov ecx,[ebx+48h]
0x10056268: sub ecx,eax              ; 元素个数
0x1005626a: mov eax,66666667h
0x1005626f: imul ecx                 ; ★ 魔数除法
0x10056271: sar edx,4
0x10056274: mov eax,edx
0x10056276: shr eax,1Fh
0x10056279: add eax,edx              ; count = (end-start) / 0x0A0
```

**魔数 `0x66666667` + `sar edx,4`** 等价于 **除以 0x0A0（160）** —— 再次印证对象步长 160 字节。这部分承担线段合并、中枢识别、买卖点判定，是 8000+ 条指令的主体。

## 四、完整反编译伪码

```c
// 对应 WNMRNEW(level_seq) —— 无脑买入状态码计算
// this = 计算容器; count = 数据点/对象数; out = 输出double[]; ctx = 上下文
int __thiscall Calc_WNMRNEW(void* this, int count, double* out, void* ctx)
{
    void*  objList;      // edi = this->pObj
    float* temp;         // ebx = new float[count]

    if (count <= 0)        return -1;
    if (ctx   == NULL)     return -1;

    objList = *(void**)this;

    // --- 1. 双缓冲初始化：out 清零 + 镜像到 temp(float) ---
    temp = new float[count];
    for (int i = 0; i < count; i++) {
        out[i]  = 0.0;
        temp[i] = (float)out[i];
    }

    // --- 2. 授权校验（功能码 0xEA63）---
    if (!ctx->vtable->Authorize(0xEA63))
        return -1;

    // --- 3. 三级流水线 ---
    sub_10060aa0(objList, count, temp);   // 打状态位  obj->field_8C ∈ {0,1,-1}
    sub_100616b0(objList);                // 按 field_8C==1 归并裁剪
    sub_10056190(objList);                // 主算法：线段/中枢/买卖点
    void* it = sub_1003f150(objList);     // 取结果容器首元素

    // --- 4. 提取状态码 field_90 写入 out[] ---
    int idx = 0;
    for (obj in objList) {                 // 步长 0xA0
        int k = obj->field_00 - 1;         // index - 1
        out[k] = (double)obj->field_90;    // ★ 状态码 → 输出
        // 其余位置补齐 0
    }

    delete[] temp;
    return 1;
}
```

## 五、逻辑链路与「无脑买入」的对应关系

```
CHBI(H,L,P)          笔：顶/底分型 (±1)
      ↓
CHDUAN               线段特征序列分型 (±1)   ← WNMR_线段 传入此序列
      ↓
WNMRNEW(seq)
  ├─ sub_10060aa0    若 seq[i]==1 且 seq[i-1]==1 → 对象 field_8C = +1
  ├─ sub_100616b0    仅保留 field_8C==1 的级别对象
  ├─ sub_10056190    核心走势计算
  └─ 输出 field_90   → VAR5  ← 公式按 2/3/5/6 分支
                         2=买入  3=止损  5=卖出  6=止盈
```

**「无脑」二字的算法含义**：`sub_10060aa0` 的判定极为直接 —— **连续两个同向线段分型（`seq[i]==seq[i-1]==1`）即置位买入标志**，不做更多结构过滤。这正是「无脑买入」名称的由来，也是三个同族公式（笔/线段/走势类型）唯一差别仅在于喂入序列级别的根本原因。

## 六、结论与局限

### 已确认
1. `sub_1003a7c0` 是 `WNMRNEW` 的**结果封装层**，真正判定在 `sub_10060aa0` + `sub_10056190`。
2. 级别对象**步长 160 (0xA0) 字节**；`+0x8C` 为信号标志，`+0x90` 为输出状态码。
3. 状态位判定依赖常量 **±1.0**（`0x1006FC50`），阈值参与比较的还有 **1.8625**。
4. 授权功能码 **0xEA63**，未授权返回 `-1`。

### 局限（需进一步工作）
- `sub_10056190`（8173 条指令）是完整缠论引擎，本次仅反编译了计数/遍历头部；**线段合并与中枢判定的具体数学公式尚未逐条还原**。
- `WNMRPRINEW`（`sub_1003a960`）读取 `+0x94` 的价格字段，其**止损/止盈价的计算比例**仍需结合 `sub_10056190` 内部逻辑确认。
- 建议用 IDA Pro / Ghidra 加载 `TAFLib.dll`，以 `0x10060aa0` + `0x10056190` 为目标做交叉引用与类型重建。
