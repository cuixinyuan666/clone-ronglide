# 遗留事项闭环：`+0x0C`/`+0x10` 字段来源与遍历索引关系
## 融立德「无脑买入线段」核心算法 · 第三批还原

> 二进制：`TAFLib.dll`（32位 PE，ImageBase `0x10000000`）
> 目标：追溯 `+0x0C`/`+0x10` 究竟由谁写入、语义是什么；并还原「邻近区间」的索引关系
> 入口链条：`CalcProc_ChBi` → `sub_1002C1D0` → `sub_1003DB40` / `sub_1003E200` / `sub_1003EF00`

---

## 一、结论速览

| 问题 | 结论 |
| --- | --- |
| `+0x0C` / `+0x10` 是什么？ | **笔/线段端点的 LOW / HIGH 价格**（不是原始 K 线高低点） |
| 谁写入？ | 由 `sub_1002C1D0` 预填充 → `sub_1003DB40` 计算 → 最终由 `sub_1003EF00` 按方向标注 |
| 输入数据是什么？ | **double 精度的价格序列**（`+0x0C`/`+0x10` 源自 double 数组转 float） |
| `+0x20` 方向标志谁写？ | `sub_1003EF00`（1=上涨段，-1=下跌段） |
| 「邻近区间」索引关系 | 通过对象内的 `+0x04`/`+0x08`/`+0x14` 索引字段链接前后端点 |

**核心发现**：`+0x0C`/`+0x10` **不是** K 线高低点，而是**笔端点价**。这修正了第二批报告中「需确认」的悬置问题。

---

## 二、输入数据结构（新发现）

### 2.1 `sub_1002C1D0` 揭示的输入布局

```asm
0x1002c24d: fld qword ptr [edx+eax]     ; ★ 读 double (8字节)
0x1002c250: add ecx,4                   ; 输出 float 数组1，步长 4
0x1002c257: add eax,8                   ; 输入 double 数组，步长 8
0x1002c25d: fld qword ptr [eax-8]       ; 再读一个 double
0x1002c260: fstp dword ptr [ecx-4]      ; → float 数组2
0x1002c263: fst qword ptr [edi+eax-8]   ; 第三个数组（原位 double）
```

**双数组设计**：
- 输入：**double[] 价格序列**（步长 8 字节）
- 输出 1：`float[]`（步长 4）—— 副本 A
- 输出 2：`float[]`（步长 4）—— 副本 B
- 输出 3：原位 double 保留（步长 8）

这解释了为何下游能用 `fld dword ptr [esi+0Ch]` 快速访问 —— 数据已被降精度为 float 以加速。

### 2.2 算法版本分支（`sub_1002C1D0` 尾部）

```asm
0x1002c299: cmp esi,0Bh   → sub_1003F170(edi,1)   ; P=11 老笔
0x1002c29e: cmp esi,0Ch   → sub_1003F170(edi,2)   ; P=12 新笔
0x1002c2a3: cmp esi,15h   → sub_1004B1E0(edi,1)   ; P=21 (分型笔?)
0x1002c2a8: cmp esi,16h   → sub_1004B1E0(edi,2)   ; P=22
0x1002c2ad: cmp esi,1Fh   → sub_1004F430(edi,1)   ; P=31
0x1002c2b2: cmp esi,20h   → sub_1004F430(edi,2)   ; P=32
0x1002c30b: cmp esi,33h   → sub_1006A040(edi)     ; P=51 分型笔
```

**这直接对应 `CHBI(H,L,P)` 的 P 参数**：`0x0B=11`（老笔）、`0x0C=12`（新笔）、`0x33=51`（分型笔）—— 与 `TAFunc.xml` 文档完全一致。

## 三、笔端点构造算法（`sub_1003DB40`，412 条指令）

### 3.1 顶底分型判定核心

```asm
0x1003db5f: mov eax,66666667h
0x1003db66: sar edx,6            ; ★ ÷160 (0xA0) → 对象步长
...
0x1003dbd1: mov esi,[esp+190h]   ; esi = HIGH 数组
0x1003dbd8: mov edx,[esp+194h]   ; edx = LOW 数组
0x1003dc1b: fld dword ptr [ecx+eax]   ; 读 LOW[j]
0x1003dc26: fld dword ptr [eax]       ; 读 HIGH[j]
0x1003dc52: fld dword ptr [esp+2Ch]   ; 读上一个高点
0x1003dc56: fcom st(2)                ; 比较
0x1003dc5e: test ah,1                 ; C0 → 大小关系
0x1003dc63: fcom st(2)
0x1003dc67: test ah,41h               ; C0|C3 → 相等性
```

**判定模式**：
- `test ah,1` + `jne` → 判 **小于**（C0=1）
- `test ah,41h` + `jp` → 判 **相等**（C0=0,C3=1）

这是标准的**分型包含关系处理**（缠论「包含处理」）：通过交替比较高低点，去除包含关系，识别真正的顶/底分型。

### 3.2 极限值定位

```asm
0x1003de78: fst dword ptr [esp+50h]   ; 保存候选高点
0x1003de84: fst dword ptr [esp+4Ch]
0x1003de92: fst dword ptr [esp+58h]
0x1003dec2: fst dword ptr [esp+0D4h]  ; 多路候选值
0x1003decd: fst dword ptr [esp+90h]
0x1003dedb: fst dword ptr [esp+94h]   ; 对应 +0x90/+0x94 语义的中间量
```

输出到栈局部结构，最终写回级别对象。

## 四、`+0x0C`/`+0x10`/`+0x20` 的最终写入者：`sub_1003EF00`

**这是本次研究的关键闭环证据。**

```asm
; ---- 第一段：标注上涨端点 ----
0x1003efd4: mov ecx,[edi+14h]          ; 读索引字段 +0x14
0x1003efe2: fld dword ptr [edi+0Ch]    ; ★ 读 +0x0C (该点 LOW)
0x1003efe5: fstp dword ptr [esp+3Ch]
0x1003eff9: call 1003F0D0h             ; 用 +0x04 索引查找目标对象
0x1003f01a: mov dword ptr [ebx+20h],1  ; ★★ 目标对象 +0x20 = 1 (上涨)

; ---- 第二段：标注下跌端点 ----
0x1003f02b: mov eax,[edi+4]            ; 读索引字段 +0x04
0x1003f039: fld dword ptr [edi+10h]    ; ★ 读 +0x10 (该点 HIGH)
0x1003f03c: fstp dword ptr [esp+40h]
0x1003f050: call 1003F0D0h             ; 用 +0x08 索引查找目标对象
0x1003f073: mov dword ptr [ebx+20h],0FFFFFFFFh  ; ★★ 目标对象 +0x20 = -1 (下跌)
```

### 关键推论

1. **`+0x0C`/`+0x10` 就是笔端点的 LOW/HIGH** —— 它们被读取后用于确定方向
2. **`+0x20` 由 `sub_1003EF00` 写入**，取值 `1`（上涨）/ `-1`（下跌）
3. **写入路径是间接的**：通过 `[edi+4]` / `[edi+8]` / `[edi+14h]` 索引定位「目标对象」，再写其 `+0x20`
4. 同一函数内先读 `+0x04`（索引 A）后读 `+0x08`（索引 B），对称处理两个端点

## 五、「邻近区间」索引关系（闭环）

综合 `sub_1003E200` 与 `sub_1003EF00`，还原出级别对象的**索引链接结构**：

```
级别对象 (步长 0xA0)
├── +0x00 : 序号（自身索引）
├── +0x04 : 索引 A  → 指向「前一顶点」
├── +0x08 : 索引 B  → 指向「后一顶点」
├── +0x0C : LOW  价
├── +0x10 : HIGH 价
├── +0x14 : 辅助索引（类型/级别）
├── +0x20 : 方向 (1/-1)
├── +0x88 : 分型标志 (1/-1)
├── +0x90 : 状态码 (1-6)
├── +0x94 : 实际价格
└── +0x98 : 特殊标志（见 ChBi，用于价格倍增）


sub_1003E200 中的「邻近」访问：
0x1003e26d: fld [esi+0Ch]      ; 当前点 LOW
0x1003e27e: fld [esi+10h]      ; 当前点 HIGH
0x1003e28d: lea ebx,[esi-0A0h] ; ★ 前一个点 = 当前地址 - 0xA0
0x1003e2a3: fld [ebx+0Ch]      ; 前一个点的 LOW
```

**「邻近区间」= 相邻的 0xA0 结构体**。引擎通过 `指针 ± 0xA0` 直接访问前/后一个笔端点，无需索引表。

## 六、完整数据流闭环

```
【输入】double[] 价格序列（OHLC 中的 H/L）
    ↓ sub_1002C1D0
float[] HIGH 副本 + float[] LOW 副本
    ↓ sub_1003DB40  （按 P=11/12/51 选择分型算法）
分型序列（含包含处理）
    ↓ sub_1003E200 / sub_1003EBA0 / sub_1003EF00
笔端点对象[160字节]：写 +0x0C(LOW) +0x10(HIGH) +0x20(方向)
    ↓ CalcProc_ChBi 返回 double[] 给公式
CHBI(H,L,P) → ±1 序列
    ↓ WNMR_线段 公式
CHDUAN → 线段特征序列分型
    ↓ WNMRNEW (sub_1003a7c0)
    ├─ sub_10060aa0  打 +0x8C 标志
    ├─ sub_100616b0  归并
    ├─ sub_10056190  ★ 标 +0x90(状态码1-6) +0x94(价格)
    └─ 输出 VAR5
    ↓ WNMRPRINEW (sub_1003a960)
输出 VAR6（+0x94 价格）
```

## 七、验证方法与置信度

| 结论 | 证据 | 置信度 |
| --- | --- | --- |
| `+0x0C`/`+0x10` = 笔端点 LOW/HIGH | `sub_1003EF00` 读取后用于方向判定；`sub_1003E200` 用 `-0xA0` 访邻点 | **高** |
| `+0x20` = 方向标志 | `mov [ebx+20h],1` / `,0FFFFFFFFh` 紧邻 LOW/HIGH 读取 | **高** |
| 对象步长 0xA0 | 魔数 `0x66666667 sar 6` 三处出现 | **高** |
| 输入是 double[] | `fld qword ptr` 步长 8 | **高** |
| P=11/12/51 → 分型算法 | `cmp esi,0Bh/0Ch/33h` 分支 | **高** |
| 「邻近」= ±0xA0 | `lea ebx,[esi-0A0h]` | **高** |

> 仍建议动态验证：在 `0x1003f01a`（写方向）下断点，观察 `[edi+0Ch]`（LOW）与 `[edi+10h]`（HIGH）的实际数值，与 K 线图上的笔端点对比。
