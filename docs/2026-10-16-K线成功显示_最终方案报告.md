## 二、最小可用流程（已验证，可复现）

1. **导入数据**（系统→数据导入，目录 `D:\testimp`，内含 `02#000001#1` `02#600000#1` `02#600004#1` `02#600006#1`）
   → 写盘 `Dat\His\02\1\{代码}.1`
2. **注入符号表**（frida，`tools/inject_symtab.py`；只注入沪市 market 2 即可）：
   - `inst = RDM_C.dll + 0x22580`（`dmc_QM::get_instance`）
   - `add_market(inst, 2)` = `rquo.dll + 0x47430`（返回 1）
   - `get_market(inst, 2, &shared_ptr)` = `rquo.dll + 0x58f60` → q_market*
   - `load_symtab(q_market)` = `rquo.dll + 0x280b0` → 返回 0 = 成功解析 `Sys\02\SymTable.rs`（7485 只）
3. **配置自选股** `User\SelfSymbol.xml`：
   ```xml
   <BLK N="自选股">
     <M S="2" C="600000"/>
     <M S="2" C="000001"/>
     <M S="2" C="600004"/>
     <M S="2" C="600006"/>
   </BLK>
   ```
4. **重启软件**（重启工具 `tools/restart_app.py`：taskkill→启动→关欢迎对话框→点「脱机运行」）+ 再注入符号表
5. **点左侧「自选股」** → 列表显示 600000浦发银行/000001上证指数/600004白云机场/600006东风汽车
   （此时当前股票上下文自动切到 600000）
6. **键盘精灵执行 `91`（1分钟）** → K线渲染 ✅
   - 模拟发键 `9` 打开「键盘精灵」→ WM_SETTEXT 输入 `91` → 回车/IDOK 执行

## 三、本阶段关键技术发现

### 1. 数据引擎内部 API（frida RPC 直调，thiscall，x86）
| 功能 | rquo.dll RVA | 说明 |
|---|---|---|
| 加载符号表 | 0x280b0 | 返回 0 成功；0x6c=文件不存在 |
| 创建市场 | 0x47430 | `add_market(u8)` |
| 取市场对象 | 0x58f60 | `get_market(u8, &shared_ptr)` |
| 查符号 | 0x59270 | 失败 = ret 0x68(104) |
| 历史条数 | 0x4dcc0 | `(out*, sym*, u16 item)` |
| 按位取历史 | 0x4ddd0 | `(out*, sym*, u16 item, i32 pos, i32 want, div*)` |
| 日线失败码 | — | **0x72(114) = 该品种该周期无本地数据** |

- 获 58560 条历史：`get_history_count(SH600000, item=1)` 返回 `{ret:0, count:58560}`；`by_pos` 返回 0
- `symbol_info` 结构：`+0x00` market(u8)，`+0x08` code(8B)，`+0x1c`=6，`+0x20`=0xf，`+0x28` 中文名(GBK)，`+0x44` 拼音

### 2. 市场/符号解析行为
- 代码多市场重复（000001 在沪=上证指数、深=平安银行）时按**市场号顺序**解析 → 先加载深市(1)会锁到平安银行（无数据）→ **只加载沪市(2)** 可让 000001 解析为上证指数
- 所有本地分钟数据均为沪市（`Dat/Min/02#*#1` 1387 个文件；深市无数据）

### 3. UI 自动化的坑与解法
- **软件是 DPI-Aware**：客户区物理分辨率 2160×1248，原点物理 (0,132)
- **鼠标命中区 = 绘制位置 + ≈52px（物理）**：要点击可见 y=182 的「自选」条目，需实际点 (80, 237)！已验证
- 键盘精灵：模拟键 `9` 可打开；WM_SETTEXT 到 Edit 有效；`91`=1分钟、`92`=5分钟… 命令需要列表非空（数字命令有效；6位代码搜索无效——符号搜索依赖枚举向量，仍为空）
- **frida thiscall**：NativeFunction 声明 `'thiscall'`，首参走 ECX；Interceptor 回调中符号指针在 `args[1]`

### 4. 危险操作（会死锁/需重启）
- RPC 直调 `rquo+0x49720`（get_market_symbol_vector / RDM_C GetMarketSymbolInfoVector）会导致 UI 线程死锁、frida agent 卡死 → 必须重启软件
- 重启后必须重新注入符号表（内存态）

### 5. 仍存在的已知问题（次要）
- 符号**枚举向量**为空：键盘精灵符号搜索、分类报价列表不出内容（命令搜索正常）
- 深市/其他市场无本地数据；其他品种按同样流程（自选股+91）即可显示
- 分时图（当日分时）离线无 tick 数据，属正常空白
