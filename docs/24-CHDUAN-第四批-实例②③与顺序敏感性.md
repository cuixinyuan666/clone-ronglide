| D | `[esp+0xf8]` | `[esp+0x104]` | `[esp+0x108]` | 内层候选端点 cur 快照 |

### 5.1 包含关系处理核 `0x10053c86` [B]

```
0x10053c86 (进入时 ST0 已 fstp 或由 0x100537d6 jne 直接到达):
    if (cur.H > cacheA.H) goto L2;                 ; test ah,0x5 / jp
    if (cur.L > cacheA.L) goto L2;                 ; test ah,0x5 / jp
    ; 两不 >  ⇒ cur ⊆ cacheA（或更低）
    cacheB := cacheA   (rep movsd 0x68 → 0x90)
    cacheA := cur      (rep movsd cur → 0x68)
    iterpair := {ebp, cur};   [esp+0x3c] = cur[+0x08]
    jmp 0x10053d73
L2 (0x10053cfa):
    if (cacheA.H > cur.H) goto L3;                 ; test ah,0x5 / jp（ST0=cacheA.H）
    cacheA.L := cur.L                              ; 仅低点单边刷新
    [esp+0x3c] = cur[+0x08];  jmp 0x10053d73
L3 (0x10053d2f):
    cacheB := cacheA;  cacheA := cur;  iterpair := {ebp, cur}
    [esp+0x3c] = cur[+0x08];  jmp 0x10053d73
```

**语义**：三分类 —— ① `cur ⊆ cacheA` → **整体替换（含平移 cacheB）**；② `cacheA.H > cur.H`（但 `cur.L > cacheA.L`）
→ **仅刷新低点（保高）**；③ 其余 → **上移替换**。这正是缠论"包含关系处理"的标准骨架。

## 六、96 条条件语义串 [A/B]

证据：`conditions_10053540_annotated.txt`（区域 + 缓存槽 + 落空目标）。

### 6.1 统计与镜像

| 指标 | 值 |
| --- | --- |
| 总数 | 96（① 21 / ② 22 / ③ 26 / ④ 25 / 标记 2） |
| test 型分布 | `0x5 jp` 40、`0x41 jne` 40、`0x5 jnp` 8、`0x41 je` 8 → **40/40 + 8/8 完全对称** |

最后回到步进块 `0x10053d73` 取下一项；容器走完则按选择器转入下一实例或标记阶段。

## 七、`+0x84` 四写点的完整条件 [A]

四个发布块，均为 `m[0].begin()+n`（`0x1003f0d0`）取元素后写值：

| 值 | 写点 | 所属实例（容器） | 索引来源 | 同块副作用 |
| --- | --- | --- | --- | --- |
| **1** | `10055bfa` | ④（m[2]） | `cur_m2[+0x08]` | `10055b63 [cur+0x18]=1`；`10055b7c [esp+0x64]=cur[+0x10]` |
| **2** | `10055c3f` | ④（m[2]） | `cur_m2[+0x04]` | `10055c50 [esp+0x128]=cur[+0x0C]`；出口 `10055c68 jmp 0x100535d2` |
| **3** | `10055105` | ③（m[3]） | `cur_m3[+0x08]` | `100550ac [esp+0x158]=cur[+0x10]` |
| **4** | `10055151` | ③（m[3]） | `cur_m3[+0x04]` | 出口 `esi=[esp+0x58]; jmp 0x100535d2` |

- **序号规律 = 容器(2/3) × 索引字段(B:+0x08 / A:+0x04)**：
  `1=m2.B`、`2=m2.A`、`3=m3.B`、`4=m3.A`。

  docs/16 §五 把 `10055bfa/10055c3f` 归给"实例①" → 实为 **实例④**（同走 m[2]，但属第二阶段）。

## 八、ContA / ContB 顺序敏感性（docs/21 §8 待办）[A/B/C]

**术语**：ContA = **m[2]（W+0x20）**、ContB = **m[3]（W+0x30）**（0x28 项容器）。

### 8.1 拆表函数 `0x1003eba0`（prep 首句，唯一调用点 `10053585`）[A]

```
0x1003eba0(W):
  1) 压缩 m[2] (W+0x24/+0x28)：非空 → 0x1006b050(__move) 收尾
  2) 压缩 m[3] (W+0x34/+0x38)：同上
  3) push 2; m[0].begin()+2（跳过前两个级别对象）
  4) for (it = m[5].begin; it != m[5].end; it += 0x28):      ; ★ 唯一源 = m[5] (W+0x50)
         it[+0x20] = 0
         if (it[+0x14] == +1):            ; 底分型 → ContB
              cnt++; [esp+0x54]= 1
              m0[ it[+0x04] ].+0x20 =  1;  m0[ it[+0x08] ].+0x20 = -1
              push_back(m[3], {cnt, it[+4], it[+8], it[+0C], it[+10], +1, 0, it[+1C], it[+20]})
         elif (it[+0x14] == -1):          ; 顶分型 → ContA
              cnt++; [esp+0x54]= -1
              m0[ it[+0x04] ].+0x20 =  1;  m0[ it[+0x08] ].+0x20 = -1
              push_back(m[2], {cnt, it[+4], it[+8], it[+0C], it[+10], -1, 0, it[+1C], it[+20]})
  5) ret 4
```

### 8.2 prep 的读取顺序与依赖 [A]

- 读序：**① 扫 m[2] → ② 扫 m[3] →（②置选择器）→ ③ 扫 m[3] / ④ 扫 m[2]**。
- 相位选择器 `esi`：`0`→①、`1`→③、`-1`→④；**② 只由 ① 进入**。
- 游标链 `[esp+0x5c]`（索引下界）与 `[esp+0x58]`（游标）在实例间**单向传递**
  （1005462c、1005466a、10055095、10055b86/99、10055c57）→ 依赖链 `①② → ③/④` 严格单向。
- prep 对结构体的**写点仅 11 处**（其余全只读）：4×`m0[].+0x84`、2×`m3[+0x18]`、5×`m0[].+0x24`。

### 8.3 结论

| 命题 | 结论 | 依据 |
| --- | --- | --- |
| eba0「先 append m[2] 还是 m[3]」是否影响 prep 结果 | **不敏感** [B] | prep 对每个容器做完整独立一遍；容器间交错顺序不被观察；两容器互不读改对方 |
| ②③ 都读 m[3] 是否顺序相关 | **相关但方向固定** [A] | ② 先写 m[3] 项 `+0x18=±1` 并置选择器，③/④ 后读；② 在 ③/④ 之前是硬约束 |
| m[5] 遍历顺序是否敏感 | **敏感且固定** [B] | `m0[+0x20]` 写入 last-writer-wins；m[5] 为 vector，顺序 = 插入序，非可调参数 |
| m[0] 索引是否跨项覆盖 | **静态不可判定** [C] | 需 frida 观察同一 m[0] 元素 `+0x20` 的最终值分布（**勘误候选**） |

**总判定**：**拆表顺序不敏感 [B]**；唯一顺序敏感源是 **m[5] 内 m[0] 索引的重复/交叉写入 [C]**。
