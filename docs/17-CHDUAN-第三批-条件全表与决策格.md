### 1.1 x87 精确真值表（Intel FNSTSW 语义；U=不可比）

| 组合 | 跳转条件 | 落空条件 |
| --- | --- | --- |
| `test ah,0x41` + `jne` | {≤, U} | **{>}** |
| `test ah,0x41` + `je`  | **{>}** | {≤, U} |
| `test ah,0x41` + `jp`  | {>, U} | {≤} |
| `test ah,0x05` + `jp`  | {≥, U} | **{<}** |
| `test ah,0x05` + `jnp` | **{<}** | {≥, U} |
| `test ah,0x01` + `jne` | **{<, U}** | {≥} |

> 价格数据无 NaN → U 恒不出现，上表可再简化。
> **口径对齐**：docs/05 的表格记录的是「AH&mask=0（即 ZF/PF 成立）时对应的语义」，
> 与本表「落空」列一致；其个别行（如 41h+je 记「相等」）语义偏松，列入勘误候补。

### 1.2 重要勘误（docs/16 §3.1）

-2 写点的浮点条件因 `fld` 压栈顺序应为：

```
fld prev[+0x10] ; fld cur[+0x10] ; fcompp     → ST0 = cur, ST1 = prev
test ah,0x41 ; jne else                       → 落空 = cur[+0x10] > prev[+0x10]
```
即 **`-2 条件 = prev[+0x08] > cur[+0x08] && cur[+0x10] > prev[+0x10]`**
（docs/16 写作 `prev[+0x10] > cur[+0x10]`，特此更正；`chduan.c` 已按精确式落笔）。

## 二、实例①决策格（`100535d2`–`10053d73`，中等置信）

实例①对 **m[2]** 单遍扫描，维护「缓存项 `[esp+0x68]`（0x28B 按值拷贝）+ 缓存浮点 `[esp+0x9c]/[esp+0xa0]` + 标志 `[0x12]/[0x13]`」。

```
for (it = m2.begin; it != m2.end; it += 0x28):
    ┌─ 前置: 与缓存项比较 ─────────────────────────────────────────┐
    │ if (cached_low <  cur[+0x0C]) && (cached_hi < cur[+0x10])     │  ← 05h+jp 两连
    │     缓存项 := cur; [0x12]=0; [0x13]=1; 退出实例(→0x10053d73)  │
    └──────────────────────────────────────────────────────────────┘
    ┌─ 否则: 41h+jne / 41h+je 三分支 ─────────────────────────────┐
    │ if (cached_low > cur[+0x0C]) && cached_hi <= cur[+0x10]      │
    │     → 仅更新 [esp+0xa0] := cur[+0x10]; 退出                  │
    │ if (cached_low >= cur[+0x0C])  → 仅更新[0xa0]; 退出          │
    │ if (cached_low <  cur[+0x0C])  → 缓存项 := cur;              │
    │     [0x12]=0; [0x13]=1; 退出(→0x10053d6c)                    │
    └──────────────────────────────────────────────────────────────┘
    ┌─ [0x12]==0 支路: 与缓存项自身字段三方比较(→0x10053db2) [C] ─┐
    │ fld cur[+0x0C] vs cacheItem[+0x0C]; jne → 0x10053c86         │
    │ fld cur[+0x10] vs cacheItem[+0x10]; jne → 0x10053c84         │
    │ fld (残留 cur[+0x10]) vs [esp+0x9c]; jp → 0x10053db2         │
    └──────────────────────────────────────────────────────────────┘
```

> 语义概读：**「整体更高 → 缓存上移；单边刷新 → 只更新高点缓存；更低/包含 → 缓存替换」**——
> 即缠论「特征序列」的**包含关系处理 + 单调推进**骨架（第四批给出形式化命名）。
> 实例②/③ 为同模板的偏移展开（[esp+0x13] 置位点 10053e22/10054690 对应入口），差异在第三批之后展开。
