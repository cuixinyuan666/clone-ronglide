## 一、函数概览

| 项 | 值 |
| --- | --- |
| 边界 | `0x10053540` – `0x10055fff`（`ret 4`，后随 `CC` 填充） |
| 体量 | **3064 条指令**（≈10.9KB），迄今最大单函数 |
| 调用者 | 仅 `sub_1002c710`（CHDUAN 引擎） |
| 结构 | **3 个内联实例**（同模板展开）+ 尾部**标记阶段** |

### 1.1 序言条件（`0x10053540`–`0x10053585`）

```
if (W->m[0]._Myfirst == NULL) return;                 ; [W+4]==0
n = (W[+8] - W[+4]) / 160                             ; = m[0].size()（魔数 ÷160）
if (n <= 21) return;                                  ; ★ 级别对象数 ≤21 → 直接放弃
call 0x1003eba0(W)                                    ; m[2] 预处理（读 W+0x24/+0x28 ÷0x28）
```

> 魔数除法双连：`÷160`（m[0] 元素数）与 `÷0x28=40`（m[2]/m[3] 元素数）在本函数反复出现，
> 可作「当前操作的是哪根容器」的判别指纹。

### 1.2 实例复读规律

`[esp+0x13]`/`[esp+0x12]` 两个字节标志、`rep movsd ecx=0xa`（40 字节 = 0x28 项拷贝到栈
`[esp+0x68]`）等模式在三个位置重复出现：

| 实例 | 标志置位行（10053609/100536fe/10053703 附近） | 循环头 |
| --- | --- | --- |
| ① | 10053604 / 100536fe / 10053703 | `0x100535d2` |
| ② | 10053e22 / 10053f24 / 10053f8b 附近 | （同模板+偏移） |
| ③ | 10054690 / 100547cc / 10054869 附近 | （同模板+偏移） |

> 与 `sub_10056190`（wnwr 主引擎）的「同一模板 4 次内联」同构——本函数按
> **方向（顶/底）× 角色（特征序列/候选）** 展开 3 遍。逐实例数学细节 = 第三批主题。

## 三、标记阶段完整解码 ★（本批核心）

当实例迭代终止（`esi==ebx`，10055c89）后，执行**标记阶段**（10055c91–10055ffe）。
所有权重写入统一目标：**`W->m[0][idx].+0x24`**。

### 3.1 写 -2（两处，门控 `[esp+0x13]==1`）

```
if ([esp+0x13] == 1):                       ; “本地缓存项存在”标志
    prev = m[2].last - 0x28                 ; m[2] 末项
    if (prev[+0x08] > cur[+0x08] && prev[+0x10] > cur[+0x10]):
        W->m[0][ prev[+0x08] ].+0x24 = -2   ; @10055d46
    else:
        W->m[0][ cur[+0x08] ].+0x24 = -2    ; @10055d88
```

- `cur` = 实例外层循环的当前项（`esi`）；比较为 **int 序 + x87 浮点** 双重判定。
- 浮点处：`fld prev[+0x10]; fld cur[+0x10]; fcompp; test ah,0x41; jne skip`
  （按 Intel 语义：**落下 = ST0 > ST1**；与文档 05 的极性表述存在出入，第三批用具体案例仲裁并修正）。

### 3.2 写 +2（一处）

```
if (<对称条件，基准项 [esp+0x34]/[esp+0x38] 对>):
    W->m[0][ (cur[+0x04] > base[+0x04] && f32 条件) ? cur[+0x04] : base[+0x04] ].+0x24 = +2   ; @10055e8a
```

> 注意：+2 分支读取 `[esp+0x1d0]`——因先 `push` 使栈下移 4，该槽实为 **`[esp+0x1cc]`（=W）**；
> 与其余各写点同一容器（已用原始字节复核反汇编对齐）。

### 3.3 写 -1（循环 over m[3]）

```
for (it = W->m[3].begin; it != W->m[3].end; it += 0x28):
    if (it->[+0x18] == -1):
        W->m[0][ it->[+0x08] ].+0x24 = -1   ; @10055f2f
```

### 3.4 写 +1（循环 over m[2]）

```
for (it = W->m[2].begin; it != W->m[2].end; it += 0x28):
    if (it->[+0x18] == +1):
        W->m[0][ it->[+0x04] ].+0x24 = +1   ; @10055fd7
```

### 3.5 汇总表

| 值 | 来源容器 | 条件 | 索引字段 | 写点 |
| --- | --- | --- | --- | --- |
| **-2** | m[2] 末项 vs cur | 双条件（int+float） | prev/cur `+0x08` | 10055d46 / 10055d88 |
| **+2** | cur vs 基准项 | 双条件 | cur/base `+0x04` | 10055e8a |
| **-1** | m[3] 逐项 | `item[+0x18]==-1` | `+0x08` | 10055f2f |
| **+1** | m[2] 逐项 | `item[+0x18]==+1` | `+0x04` | 10055fd7 |

> 规律与 wnwr 引擎（README §3）完全同构：**买/上方向取 `+0x04`，卖/下方向取 `+0x08`**；
> ±1 为逐项直接映射，±2 为「末项/基准 vs 当前」比较后的端点位。

## 四、调用约定与工具修正（重要）

| 函数 | 真实签名（本次实测修正） |
| --- | --- |
| `sub_1003f0d0` | **`(ebx=容器, esi=out迭代器, [esp+4]=n)`** → `container.begin()+n`（步长 0xA0，n 原样使用；越界走 `_invalid_parameter_noinfo`）② 既有文档「W 为第一参数」应读作「容器指针经 ebx 传递，W 场景即 m[0]（其数据恰在 W+4/+8）」 |
| `sub_1006a830` | 迭代器提取器：校验后返回 `iterpair[+4]`（当前元素指针） |
| `sub_1003eba0` | m[2] 预处理：读 `W+0x24/+0x28`，`÷0x28` 计数；进入 m[2] 处理链 |
| `rep movsd ecx=0xa` | 0x28 项按值拷贝到栈（`[esp+0x68]` = 项缓存槽） |

## 五、实例① 尾部片段（第三批入口）

```
10055b8c  lea esi,[esp+0x34]; call 0x1006a830   ; 迭代器对提取（push_back 辅助）
10055bcb  push m2_item[+0x08]; begin()+n → [m0elem+0x84] = 1     ; @10055bfa
10055c16  push m2_item[+0x04]; begin()+n → [m0elem+0x84] = 2     ; @10055c3f
10055c50  fld [ebp+0x0C]; fstp [esp+0x128]      ; 保存价格到栈缓存
10055c68  jmp 0x100535d2                        ; ← 循环回边（实例①主循环）
10055c89  cmp esi, ebx; je 标记阶段             ; ← 循环出口 → §3
```

- `+0x84` 写入使用与标记阶段相同的 `begin()+n` 寻址（容器 = W → m[0]）。
- `0x100535d2` 为循环回边 → 实例①= **对 m[2] 的单遍扫描 + 缓存比较**。
