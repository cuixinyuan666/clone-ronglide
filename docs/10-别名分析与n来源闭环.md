## 二、`ebx` 之谜解决:参数就是 W

修正栈跟踪后重读序言:

```asm
0x10056197: mov ebx, dword ptr [esp + 0x430]   ; 帧 E+4 → ebx = 参数
0x10056237: mov eax, dword ptr [ebx + 0x44]    ; W->m[4]._Myfirst
0x10056253: cmp eax, dword ptr [ebx + 0x48]    ; vs W->m[4]._Mylast
0x10056271: sar edx, 4                          ; ★ ÷40
0x10056281: mov esi, dword ptr [ebx + 4]        ; ★ W->m[0]._Myfirst
```

### 2.1 关键:魔数与移位

| 魔数 | 移位 | 除数 | 含义 |
|---|---|---|---|
| `0x66666667` | `sar 4` | **÷40 (0x28)** | 输入 bar 步长 |
| `0x66666667` | `sar 6` | ÷160 (0xA0) | 级别对象步长 |

> **本批修正**:序言用的是 **÷40**,即 `W->m[4]` 的元素是 **0x28 字节**,不是 0xA0。
> 批 8 的「`W->m[5]` 是 0x28 vector」结论得到**独立印证**(m[4]、m[5] 均为 0x28 序列)。

### 2.2 参数是 W,不是裸 vector

`W` 是含 **8 个 16 字节内嵌 vector 记录**的上下文类(批 7 模型),记录位于
`+0x00, +0x10, +0x20, +0x30, +0x40, +0x50, +0x60, +0x70`,每记录
`{hdr, _Myfirst, _Mylast, _Myend}`。

| 成员 | 记录基址 | 数据指针 | 元素尺寸 | 语义 |
|---|---|---|---|---|
| **m[0]** | `+0x00` | `+0x04` / `+0x08` | **0xA0** | **级别对象**(笔/线段端点) |
| m[4] | `+0x40` | `+0x44` / `+0x48` | **0x28** | 输入 bar |
| m[5] | `+0x50` | `+0x54` / `+0x58` | 0x28 | 输入 bar(另一序列) |

**`sub_1003f0d0(W, out, n)` 用 `[W+4]`/`[W+8]` → 即 `W->m[0]`** ✓
(记录 0 的基址正是 `W+0x00`,故 `+4`/`+8` 即其 `_Myfirst`/`_Mylast`。)

> 批 9 的「`[esp+43Ch]` = 参数」正确;本批进一步确认**参数是 W**,而 W 的 m[0] 才是 0xA0 vector。

## 三、序言的两项初始化

```asm
;; ① 遍历 W->m[0]（0xA0 元素），清零每个元素的 +0x88
0x10056281: mov esi, dword ptr [ebx + 4]        ; W->m[0]._Myfirst
0x10056288: cmp esi, dword ptr [ebx + 8]        ; vs _Mylast
0x100562cb: mov dword ptr [esi + 0x88], edi     ; ★ element->+0x88 = 0
0x100562d8: add esi, 0xa0                        ; ★ 步长 0xA0
0x100562de: jmp 0x10056290

;; ② 为 W->m[4] 建立迭代器，存入 [E-1064]/[E-1060]
0x100562e0: mov edi, dword ptr [eax + 0x44]     ; W->m[4]._Myfirst
0x100562e5: lea esi, dword ptr [eax + 0x40]     ; ★ &W->m[4]（记录基址 +0x40）
0x100562f5: mov dword ptr [esp + 0x10], esi     ; [E-1064] = &W->m[4]
0x100562f9: mov dword ptr [esp + 0x14], edi     ; [E-1060] = W->m[4]._Myfirst
```

> ① 印证了 `+0x88` 是「分型标志」(批 4 结论),且**每次调用引擎都会先全部清零**。
> ② 建立了后续填充循环所需的两个量:`&W->m[4]`(容器)与其 `_Myfirst`(起点)。

## 四、🔑 迭代器区块的填充循环(本批核心)

### 4.1 循环全文

```asm
0x100567a1: mov esi, dword ptr [esp + 0x14]     ; esi = [E-1060] = W->m[4]._Myfirst
0x100567a5: mov edx, dword ptr [esp + 0x7c]     ; edx = [E-956] = &W->m[4]
0x100567a9: add esi, 0x28                        ; ★ esi += 0x28（从第 2 个 bar 开始）
0x100567ac: xor edi, edi                         ; i = 0
0x100567ae: lea ebx, [esp + 0x18]               ; ★ ebx = &block（帧 E-1056）
0x100567b2: mov eax, dword ptr [edx + 8]        ; eax = W->m[4]._Mylast
0x100567b5: cmp dword ptr [edx + 4], eax        ; 边界校验
0x100567cc: mov ecx, dword ptr [esp + 0x10]     ; ecx = &W->m[4]
0x100567d0: cmp ecx, edx                        ; 容器一致性校验
0x100567de: cmp esi, eax                        ; if (esi == _Mylast) → 退出
0x100567e0: je 0x10056806
0x100567e2: cmp edi, 8                          ; if (i == 8) → 退出
0x100567e5: mov eax, dword ptr [esp + 0x10]     ; eax = &W->m[4]
0x100567e9: mov dword ptr [ebx], eax            ; ★ block[i]._Mycont = &W->m[4]
0x100567eb: mov dword ptr [ebx + 4], esi        ; ★ block[i]._Myptr  = esi
0x100567ee: je 0x1005680f
0x100567f0: cmp esi, dword ptr [eax + 8]        ; 校验 _Myptr <= _Mylast
0x100567fb: add esi, 0x28                        ; ★ 下一个 bar
0x100567fe: add edi, 1                           ; i++
0x10056801: add ebx, 8                           ; ★ 下一个 block 元素
0x10056804: jmp 0x100567b2
```

### 4.2 等价 C++

```c
/* 把 block[0..8] 填成 W->m[4] 中连续 9 个 bar 的受检迭代器 */
CheckedIter* block = (CheckedIter*)&frame[0x18];      /* 9 × 8 = 72 字节 */
LevelObj28*  p     = W->m[4]._Myfirst + 1;            /* ★ 从第 2 个 bar 开始 */
int          i     = 0;
while (p != W->m[4]._Mylast && i != 8) {
    block[i]._Mycont = &W->m[4];
    block[i]._Myptr  = p;
    p += 1;                                           /* +0x28 */
    i += 1;
    block += 1;                                       /* +8 */
}
```

### 4.3 自洽性校验

| 项 | 值 | 说明 |
|---|---|---|
| 区块字节数 | 72 = `[esp+0x18]`..`[esp+0x5F]` | 序言连续清零范围 ✓ |
| 元素数 | 9（循环界 `i != 8` → i = 0..8） | 72 ÷ 8 = 9 ✓ |
| 元素尺寸 | 8 字节 | `{_Mycont, _Myptr}` ✓ |

**三者完全一致 —— 机制确认无误。**

## 五、🔑 `n` 的来源闭环(最终)

### 5.1 链条

```
block[0] = {&W->m[4], W->m[4][1]}      ← 第 2 个 bar
block[1] = {&W->m[4], W->m[4][2]}
...
block[5] = {&W->m[4], W->m[4][6]}      ← ★ 第 7 个 bar（0 基索引 6）
...
block[8] = {&W->m[4], W->m[4][9]}
```

买入块使用 `block[5]`:

```asm
0x1005a15c: cmp dword ptr [esp+0x40], 0        ; block[5]._Mycont != NULL
0x1005a165: mov ecx, dword ptr [esp+0x40]      ; ecx = block[5]._Mycont = &W->m[4]
0x1005a169: mov edx, dword ptr [esp+0x44]      ; edx = block[5]._Myptr
0x1005a16d: cmp edx, dword ptr [ecx+8]         ; _Myptr vs W->m[4]._Mylast
0x1005a174: mov eax, dword ptr [esp+0x44]      ; eax = block[5]._Myptr
0x1005a17b: fld dword ptr [eax+0x10]           ; ★ bar->+0x10
0x1005a1cd: mov eax, dword ptr [esp+0x44]
0x1005a1d1: mov eax, dword ptr [eax+8]         ; ★★ n = bar->+0x08
0x1005a1d4: mov ebx, dword ptr [esp+0x43c]     ; ebx = W
0x1005a1db: push eax                            ; n
0x1005a1e3: call 1003F0D0h                      ; out = W->m[0].begin() + n
0x1005a1fa: mov dword ptr [esi+0x90], 1        ; 写状态码到 W->m[0] 的元素
```

### 5.2 结论

> **`n` = `W->m[4]` 中第 7 个 0x28 字节 bar 的 `+0x08` 字段。**
> 该值被用作 **`W->m[0]`(0xA0 级别对象 vector)的下标**。
>
> 即:**0x28 bar 的 `+0x08` 是一个指向级别对象的索引。**

### 5.3 原始问题最终正名

| 版本 | 提问对象 | 状态 |
|---|---|---|
| 批 7–9 | 「0xA0 元素的 `+0x04`/`+0x08` 是 0 基还是 1 基」 | ❌ **对象错误** |
| **批 10** | **「0x28 bar 的 `+0x08` 是 0 基还是 1 基」** | ✅ **正确提法** |

### 5.4 支持「1 基」的间接证据

填充循环**从 `_Myfirst + 0x28`(第 2 个 bar)开始**,跳过第 0 个 bar:

```asm
0x100567a9: add esi, 0x28        ; 跳过 bar[0]
```

> 若 bar 序号与级别对象序号同源,则「跳过第 0 个」暗示 **bar[0] 是哨兵/基准**,
> 从而真实元素从 1 开始编号 —— 与 `+0x00` 为 1 基(批 4)一致,**支持 1 基假设**。
> 但这仍是**间接证据**,需定位 bar 的 `+0x08` 写入点方能定论。
