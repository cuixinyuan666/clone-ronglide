## 一、结论速览

「无脑买入线段」**不是一段独立可编辑的脚本文件**，而是由三层构成：

| 层级 | 载体 | 文件路径 | 作用 |
| --- | --- | --- | --- |
| ① 菜单入口 | 命令号 4431 | `Sys\Mainmenu.xml:76` | 菜单「缠论 → 无脑买入线段」 |
| ② 公式源码 | 公式 `WNMR_线段` | `TAF\SysTA.taf`（GBK 编码，偏移约 43389） | 主公式体（可直接读取） |
| ③ 核心算法 | 函数 `WNMRNEW` / `WNMRPRINEW` | `TAFLib.dll` 导出 `CalcProc_wnmrnew` / `CalcProc_wnmrprinew` | 真正的信号判定与价格计算（编译为机器码） |

**关键点**：公式体（②）是明文通达信语法，可直接提取；但**判定的核心数学逻辑（③）被编译进 DLL，不在任何文本文件里**，需通过逆向工程（已有产物）解读。

## 三、公式源码（明文，可直接提取）

### 3.1 `WNMR_线段`（主指标，对应菜单 4431）

```
VAR1:=CHBI(H,L,P);
DRAWLINE(VAR1 =-1, L, VAR1 =1, H, 0) COLORRED, LINETHICK1;
DRAWLINE(VAR1 =1, H, VAR1 =-1, L, 0) COLORGREEN, LINETHICK1;

VAR2:=CHDUAN;
DRAWLINE(VAR2=1,H,VAR2=-1,L,0),COLORBLUE;
DRAWLINE(VAR2=-1,L,VAR2=1,H,0),COLORBLUE;

VAR5:=WNMRNEW(VAR2);
VAR6:=WNMRPRINEW;
DRAWTEXT(VAR5=2, VAR6,STRCAT(' 买入价: ',VAR2STR(VAR6,DIGIT))),COLORCYAN;
DRAWTEXT(VAR5=3, VAR6,STRCAT(' 止损价： ',VAR2STR(VAR6,DIGIT))),COLORRED;
DRAWTEXT(VAR5=5, VAR6,STRCAT(' 卖出价: ',VAR2STR(VAR6,DIGIT))),COLORGREEN;
DRAWTEXT(VAR5=6, VAR6,STRCAT(' 止赢价： ',VAR2STR(VAR6,DIGIT))),COLORRED;
DRAWICON(VAR5=2,L,1);
DRAWICON(VAR5=5,H,2);
SELECT(COUNT(VAR5=2,M)>=1);
ALERT(COUNT(VAR5=2,M)>=1,'无脑买入B');
```

### 3.2 同族公式对比

| 公式名 | 标题 | 输入（第 1 参数） | 提示语 |
| --- | --- | --- | --- |
| `WNMR_笔` | 基于笔划分下的无脑买入 | `WNMRNEW(VAR1)`，VAR1=CHBI | 同族 |
| `WNMR_线段` | 走势分解的无脑买入 | `WNMRNEW(VAR2)`，VAR2=CHDUAN | 同族 |
| `WNMR_走势类型` | 走势分解的无脑买入 | `WNMRNEW(VAR3)`，VAR3=CHZSDG(VAR2) | 同族 |

三者唯一差别是**喂给 `WNMRNEW` 的级别对象不同**：
- 笔级：`CHBI`（笔的顶/底分型，返回 ±1）
- 线段级：`CHDUAN`（线段特征序列的顶/底分型，返回 ±1）← **本指标**
- 走势级：`CHZSDG(CHDUAN)`（线段中枢递归）

### 3.3 关键函数返回值语义（来自 `TAFunc.xml`）

- `CHBI(H,L,P)`：`P=11` 老笔，`P=12` 新笔，`P=51` 分型笔；返回 `-1` 底分型 / `1` 顶分型。
- `CHDUAN`：返回 `-1` 特征序列底分型 / `1` 特征序列顶分型。**调用前必须先调用 `CHBI`**。
- `WNMRNEW(序列)`：返回**状态码**，取值含义见下。

## 四、核心计算逻辑解读

### 4.1 输入参数

| 参数 | 含义 |
| --- | --- |
| `H, L, P` | 内置宏：最高价、最低价、笔/分型算法版本（11/12/51） |
| `DIGIT` | 内置宏：当前品种小数位数（用于价格格式化） |
| `M` | 内置宏：当前周期 K 线数量（用于 `COUNT` 计数） |
| 传给 `WNMRNEW` 的第 1 参 | 级别对象序列（本指标为 `CHDUAN` 结果，±1） |

### 4.2 信号判定规则（状态码 VAR5）

`WNMRNEW` 返回值经公式消费后可推断出完整状态机：

| VAR5 | 含义 | 绘制动作 |
| --- | --- | --- |
| `2` | **买入信号** | 标「买入价」+ 底部图标 `DRAWICON(...,1)` |
| `3` | 止损位 | 标「止损价」 |
| `5` | **卖出信号** | 标「卖出价」+ 顶部图标 `DRAWICON(...,2)` |
| `6` | 止盈位 | 标「止赢价」 |

### 4.3 触发条件

```
选中条件: SELECT(COUNT(VAR5=2, M) >= 1)
告警条件: ALERT(COUNT(VAR5=2, M) >= 1, '无脑买入B')
```
即：**在当前周期（M 根 K 线）内，只要出现过至少一次「买入信号（VAR5=2）」，该股即被选中并触发「无脑买入B」告警。**

### 4.4 价格计算（`WNMRPRINEW`）

- 逆向显示 `sub_1003a960` 对每个级别对象结构体（步长 `0xA0` 字节）逐条遍历，读取偏移 `+0x94` 处的 float 字段并写入结果数组。
- 对应通达信侧 `VAR6:=WNMRPRINEW;`，用于输出「买入价/止损价/卖出价/止赢价」四个价位标签。
- 说明**买/卖/止损/止盈价并非简单用 H/L**，而是由 DLL 内部按线段结构字段计算得出。

### 4.5 底层算法（`sub_1003a7c0`，wnwrnew 实际计算体）

逆向调用图显示其依赖：
- `sub_1003f150` —— 数据容器/向量遍历辅助
- `sub_10056190` —— 数值运算
- `sub_10060aa0` —— 数学函数

> 逐条指令级还原未在现有报告中展开；若要精确复刻，需对 `0x10039e10`（旧版 `wnwr`）/`0x1003a7c0`（新版 `wnwrnew`）做进一步反编译。

> 注：软件同时保留了**旧版函数** `WNMR`/`WNMRPRI`（`?CalcProc_wnmr` @ `0x10011b20` / `?CalcProc_wnmrpri` @ `0x10011c20`），供历史公式兼容。

## 七、重要提示

1. **授权限制**：`WNMRNEW`/`WNMRPRINEW` 内部调用 `Authorize` 校验，属付费/授权版功能，未授权时可能返回空值。
2. **依赖前置**：公式先调用 `CHBI` 建立笔，再调用 `CHDUAN` 求线段，**顺序不可颠倒**（否则 `CHDUAN` 结果无效）。
3. **级别差异**：三个 `WNMR_*` 公式共用同一算法，仅输入级别不同——本指标传的是**线段（CHDUAN）**结果。
4. **完全复刻的难点**：`sub_1003a7c0` 的具体数学公式（价格偏移量、止损止盈比例）需进一步反编译才能 100% 还原。
