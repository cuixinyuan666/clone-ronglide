## 1. 循环/跳板/转换块结构 [A]

- **跳板 `0x100535d2`**（多入边汇合点）：
  ```
  ebx = W; eax = [W+0x38](=m[3].end); ebx += 0x30 (=&m[3]); cmp [ebx+4](m[3].begin),eax
  test esi, esi ; jne 0x10054673      ; esi!=0 → ②③④ 侧
  (esi==0) → 0x100535f2 → 建实例① 三联 + [esp+0x14]=&m[2] → 0x1005361c
  ```

  入边：`0x10054614`→、`0x10054650`→、`0x10055147`→、`0x10055164`(jne)→、`0x10055c68`→ 等。
- **实例① = 遍历 m[2]**（W+0x20，0x28 项）：

  - `0x10053646  cmp ebx,esi; je 0x10053db2` → **m[2] 走完 → 进实例②**（转换块）。

## 2. 栈缓存槽图 [A]

四个 **0x28 字节按值缓存** + 其 H/L 子槽（`+0x0C`→H、`+0x10`→L，与 0x28 项字段一致）：

| 缓存 | 基址 | H 子槽 | L 子槽 | 角色（本批推定） |
| --- | --- | --- | --- | --- |
| A | `[esp+0x68]` | `[esp+0x74]` | `[esp+0x78]` | m[2] 侧「prev」 |
| B | `[esp+0x90]` | `[esp+0x9c]` | `[esp+0xa0]` | m[2] 侧「cur 快照」 |
| C | `[esp+0xd0]` | `[esp+0xdc]` | `[esp+0xe0]` | m[3] 侧「prev」 |
| D | `[esp+0xf8]` | `[esp+0x104]` | `[esp+0x108]` | m[3] 侧「cur 快照」 |

## 4. 深层分支 [A/B]

- **`0x10053db2`**＝实例①→② 转换块（见 §1），非"深层判定"。它先 `[esp+0x34]/[esp+0x38]` 构造 m[2] 迭代器对，
  再 `[esp+0x1cc]` 取 W、`[esp+0x14c]` 取 n，落进实例②入口。
- **`0x10053c84`/`0x10053c86`** ＝[0x12]==0 支路的**包含关系处理核**（docs/17 §二 记为"与缓存项自身字段三方比较"）：
  ```
  0x10053c86: if cur.H > cacheA.H → 0x10053cfa          ; ah,5 jp
              if cur.L > cacheA.L → 0x10053cfa          ; ah,5 jp
              ; 两不>：cur ⊂ cacheA（或更低）→ 整体替换
              cacheB := cacheA (rep movsd 0x68→0x90)
              cacheA := cur    (rep movsd ebx→0x68)
              iterpair := {ebp, ebx}; [esp+0x3c] = cur[+0x08] ; jmp 0x10053d73
  0x10053cfa: if cacheA.H > cur.H → 0x10053d2f          ; ah,5 jp（ST0=cacheA.H）
              cacheA.L := cur.L  ; 仅刷新低点     ; [esp+0x3c] = cur[+0x08] ; jmp 0x10053d73
  0x10053d2f: cacheB := cacheA; cacheA := cur; iterpair := {ebp,ebx}; [esp+0x3c]=cur[+0x08] ; jmp 0x10053d73
  ```
  → **「包含则合并（保高点/刷低点）/ 不包含则整体上移」**，即缠论包含关系处理的标准骨架。 [B]
- **`0x10053d73`** ＝循环步进块（`ebx += 0x28; jmp 0x1005361c`），是 §2 三条支路的公共出口。

## 8. ContA / ContB 顺序敏感性 [A/B]

**术语**：ContA = **m[2]（W+0x20）**、ContB = **m[3]（W+0x30）**（0x28 项容器）。

### 8.1 拆表函数 `0x1003eba0`（prep 首句调用，唯一调用点 `10053585`）

```
0x1003eba0(W):
  1) 压缩 m[2]（W+0x24/+0x28，÷0x28 计数）—— 若非空 → 0x1006b050(__move) 收尾
  2) 压缩 m[3]（W+0x34/+0x38）—— 同上
  3) push 2; begin()+2 → m[0] 起始指针（跳过前 2 个级别对象）
  4) for (it = m[5].begin; it != m[5].end; it += 0x28):      ; ★ 唯一数据源 = m[5]（W+0x50）
       it[+0x20] = 0
       if (it[+0x14] == +1):                                ; 底分型
            cnt++; [esp+0x54]=1
            m0[ it[+0x04] ].+0x20 =  1                       ; ← 写 m[0]（索引 A）
            m0[ it[+0x08] ].+0x20 = -1                       ; ← 写 m[0]（索引 B）
            push_back( m[3] (W+0x30), {cnt, it[+4], it[+8], it[+0C], it[+10], +1, 0, it[+1C], it[+20]} )
       elif (it[+0x14] == -1):                              ; 顶分型
            cnt++; [esp+0x54]=-1
            m0[ it[+0x04] ].+0x20 =  1
            m0[ it[+0x08] ].+0x20 = -1
            push_back( m[2] (W+0x20), {同上, -1, ...} )
  5) ret 4
```
- **单遍扫 m[5]**，按 `it[+0x14]` 分流 append 到 m[2] 或 m[3]；**同容器内保持 m[5] 原序**。
- 同时把 m[0] 的两个端点置 `+0x20 = +1 / -1`（"双向端点"标志）。

### 8.2 prep 的读取顺序与依赖

- 读序：**① 扫 m[2] → ② 扫 m[3] → （②选出下一阶段）→ ③ 扫 m[3] / ④ 扫 m[2]**。
- 阶段选择器 `esi`：`0`→①、`1`→③、`-1`→④；②由①在 m[2] 走完时**唯一进入**（`0x10053646 je 0x10053db2`）。
- 游标链：`[esp+0x5c]`（索引下界）与 `[esp+0x58]`（游标/相位）在实例间**单向传递**
  （1005462c、1005466a、10055095、10055b86/99、10055c57…）→ 依赖链 ①② → ③/④ 是**严格单向**的。

### 8.3 结论

| 命题 | 结论 | 依据 |
| --- | --- | --- |
| eba0 的「先 append 到 m[2] 还是 m[3]」是否影响 prep 结果 | **不敏感** | prep 对每个容器做**完整独立**一遍；容器间交错顺序不被观察；两容器互不读改对方 |
| m[5] 遍历顺序是否敏感 | **敏感（但顺序固定）** | `m0[+0x20]` 写入为 last-writer-wins；若同一 m[0] 索引在不同 m[5] 项中以 A/B 角色重复出现 → 后写覆盖。m[5] 是 vector，顺序即插入序，非可调参数 |
| ③/④ 之间顺序 | **敏感（相位依赖）** | ② 在 10054622/1005465e 写 m[3] 项 `+0x18 = ±1` 并置 `esi`；③/④ 读该标志与 `[esp+0x54]` |
| 静态不可判定项 | m[5] 索引是否跨项重叠 | 需 frida 观察 m[0] 元素的 `+0x20` 最终值分布 |

→ **总判定：拆表顺序不敏感 [B]；唯一顺序敏感源是 m[5] 内 m[0] 索引的重复/交叉写入 [C]，需动态验证。**
