极值/下标成对关系（本批结案）
=================================================================================================
     ZG (上沿) : 价 +0x19 , 下标 +0x15      取 min(相邻高点)
     ZD (下沿) : 价 +0x25 , 下标 +0x21      取 max(相邻低点)
     GG (最高) : 价 +0x31 , 下标 +0x2d      取 max(高点)      ← edb0 判据直证
     DD (最低) : 价 +0x3d , 下标 +0x39      取 min(低点)      ← edd0 判据直证
  ⇒ 与缠论「中枢四值 ZG/ZD/GG/DD」定义一致 [A]

跨字段不变式（本批验证）
=================================================================================================
1. 区间嵌套:  DD <= ZD <= ZG <= GG                                      (定义式必然)        [A]
2. 重叠门:    dir==-1 ⇒ ZG >= C0[i].p2(=low) ∧ ZD <= C0[i].p1(=high)     ⇒ [ZD,ZG] ∩ [low,high] ≠ ∅  [A]
              dir==+1 ⇒ ZD <= C0[i].p1(=high) ∧ ZG >= C0[i].p2(=low)     (同上, 0x1000fa40)
3. 段方向门:  C0[startBar].dir == rec->dir (段方向 = 起点的 C0 方向)                          [A]
4. 段长门:    span = endBar - startBar + 1 ; 建段初检 span 需 >3 (i+3<=n)                     [A]
              commit(0x1000f0e0) 需 span >= 3; find(0x1000f200) 过滤 span > 3                 [A]
5. A/B 门:    A = C0[startBar+1].idx , B = C0[endBar(或 endBar-1)].idx ⇒ 输出区间按「分型点 bar」  [A]
=================================================================================================

无法静态定性的点（[B] + 最小实验设计）
=================================================================================================
- 点1 slot 字节 {3,4,5,6,0xfa,0xfb,0xfc,0xfd} 的语义: 疑「segment 端点角色码」。
     最小实验: frida hook 0x1000ee30 打印 (rec->self, al, arg0, arg1, C3 目标下标) → 归纳 al↔角色。
- 点2 +0x41 barIdx 的写点: 本批未在 8 支中直证（疑由 0x1000ee30 写）。
     最小实验: hook 后 dump C1 全部 rec, 对照 Bs worker 读 [ptr-0x14] 的正确性。
- 点3 +0x45..0x54 未定性: 疑 slot 计数 / 角色位图。
     最小实验: 断点于 10010f55 打印 rec+0x45..0x54 全 16B 与其后变化。
- 点4 extend 支 1000fb7d 的「与 C0[startBar] 比较却取 C0[startBar+1] 值」是否原程序特性。
     最小实验: 构造 span<=3 且 C0[i].p1 >= C0[startBar].p1 的输入, 观察 rec.ZG 落点。
