[1] 函数签名（栈槽逐点换算后自洽）
--------------------------------------------------------------------------------
  进入 esp=P；序言 push ebx/ebp/esi/edi ⇒ 体内 esp=P-0x10
    调用式（由 0x10011170 / 0x10011360 四处调用点直证）:
      sub_1000ee30(engine /*arg0, 经 ebp*/, rec /*arg1, 压栈*/, i /*ecx*/, slot /*al*/)
    - arg0 = engine    : [ebp+0x2c]=C0.count, [ebp+0x20]=C0.base, [ebp+0x40]=C2.base
    - arg1 = rec       : 段记录指针（写 rec[+0x45 + s*4] = i）
    - ecx  = i         : bar 下标
    - al   = slot      : signed char（符号 = 方向档，见 [3]）
  返回: void（ret 8 仅清 2 个栈参）
  调用点: 0x1001126a(seg_finalize), 0x1001146b / 0x10011484 / 0x100114e7(seg_advance)

[2] 主体流程（行号见 chlib_1000ee30.txt）
--------------------------------------------------------------------------------
  L30   if (rec == 0) return;                                   ; 1000ee30
  L42   if (i < 0 || i >= engine[+0x2c]) return;                ; 1000ee46 / ee4e
  L46   if (abs(slot) - 1 > 8) return;                          ; 1000ee57..ee65 (slot ∈ ±1..±9)
  L53   s = sub_1000edf0(abs(slot) - 1);                        ; 1000ee6b → 归一槽 0..3
  L54   if (s < 0) return;                                      ; 1000ee70
  L56   c0 = C0.base + i*0x31;
  L60   if (c0->mark(+0x0c) & 1) return;                        ; 1000ee82 该 bar 已登记
  L63   if (slot < 0 && c0->dir(+0x00) != +1) return;           ; 1000ee90-97  ★方向门
  L68   if (slot > 0 && c0->dir          != -1) return;         ; 1000ee9f-a4  ★方向门
  --- 主写 (C2[i], stride 0x18) ---
  L80   C2[i].id   (+0x00)      = (c0->dir == -1) ? c0->idxA(+0x11) : c0->idxB(+0x15);
  L82   C2[i].ptr  (+4 + s*4)   = rec;
  L83   C2[i].slotB(+0x14 + s)  = slot;
  L85   rec[+0x45 + s*4]        = i;
  --- 镜像分支 (仅 slot ∈ {6,8,0xfa,0xf8}) ---
  L86   slot==0xfa || slot==0xf8  → MIRROR_A (0x1000ef4a)
  L89   slot==6    || slot==8     → MIRROR_B (0x1000eeeb)
  MIRROR_B:  j=i+2; j<count; 要求 C0[j].p1(+0x19) < C0[i].p1 ; C0[j].mark 未置
             newSlotRaw = (slot==6) ? 9 : 2            ; (slot!=6)-1 & 7 + 2
  MIRROR_A:  j=i+2; j<count; 要求 C0[j].p2(+0x21) > C0[i].p2 ; C0[j].mark 未置
             newSlotRaw = (slot==0xfa) ? 0xF7 : 0xFE   ; (slot!=0xfa)-1 & 0xF9 + 0xFE
  EMIT2:     s2 = sub_1000edf0(abs((s8)newSlotRaw) - 1);  // 两路均 → 1
             C2[j].id = (C0[j].dir == -1) ? C0[j].idxA : C0[j].idxB;
             C2[j].ptr  [+4 + s2*4] = rec;
             C2[j].slotB[+0x14+s2]  = newSlotRaw;   // 存原始字节
             rec[+0x45 + s2*4]      = j;

[3] ★ slot 归一化表 0x1000edf0（9 项 → 4 槽）
--------------------------------------------------------------------------------
  形态: jmp dword ptr [eax*4 + 0x1000ee0c]
  表体: 0x1000ee0c..0x1000ee2f = 9 × 4 = 0x24 字节（末尾恰接函数体 0x1000ee30）
  表项目标桩: 0x1000edf7(ret 0) / 0x1000edfa(ret 1) / 0x1000ee00(ret 2) / 0x1000ee06(ret 3)
  索引 idx = |slot| - 1（调用点已先把 slot 取绝对值再减 1，并 cmp 8 / ja 界检）

    idx :  0   1   2   3   4   5   6   7   8
    槽  :  0   1   2   3   3   3   3   0   1

  raw slot | 有符号 | |slot|-1 | 归一槽 | 证据地址
  ---------+--------+---------+--------+----------------
     3     |  +3    |    2    |   2    | 1000ee57..ee6b
     4     |  +4    |    3    |   3    | 同上
     5     |  +5    |    4    |   3    | 同上
     6     |  +6    |    5    |   3    | 同上
     8     |  +8    |    7    |   0    | 同上
     0xfd  |  -3    |    2    |   2    | 同上
     0xfc  |  -4    |    3    |   3    | 同上
     0xfb  |  -5    |    4    |   3    | 同上
     0xfa  |  -6    |    5    |   3    | 同上
     0xf8  |  -8    |    7    |   0    | 同上

  ⇒ 归一槽**只由 |slot| 决定**；符号仅决定方向门（负 ⇒ 要求 C0.dir==+1；正 ⇒ 要求 C0.dir==-1）。
  ⇒ C2 的 4 个并发槽: 槽2 = 「±3」档 / 槽3 = 「±4,±5,±6」档 / 槽0 = 「±8」档 / 槽1 = 仅镜像分支写入。
  ⇒ 本批把第一批列出的 {3,4,5,6,0xfa,0xfb,0xfc,0xfd} **补齐 +{8, 0xf8}**（同落槽 0）。

[4] C2 记录布局（stride 0x18）[A]
--------------------------------------------------------------------------------
  +0x00       i32    C0 分型 id（dir==-1 取 C0.idxA(+0x11)，否则 C0.idxB(+0x15)）
  +0x04+s*4   ptr    段记录指针 rec（按归一槽 s = 0..3 共 4 槽）
  +0x14+s     i8     该槽的 slot **原始字节**（不归一）
  写点: 1000eec4 / 1000eeca / 1000eece（主写）；1000efb9 / 1000efbf / 1000efc3（镜像）
  读点: 0x10011500 / 0x10011660 / 0x100117b0 以 slotB[0](+0x14)<0 取 ptr[0](+4)、
        slotB[3](+0x17)<0 取 ptr[3](+0x10)  作为 V 生产的入口

[5] rec[+0x45 + slot*4] = bar 下标
--------------------------------------------------------------------------------
  主写: 1000eed2 `mov [ecx + eax*4 + 0x45], esi`      (esi = i)
  镜像: 1000efc7 `mov [esi + eax*4 + 0x45], edi`      (edi = i+2)
  ⇒ 段记录自持「该归一槽对应的 bar 下标」表（4 项），供后续查找复用。

[6] 遗留（本批不掩盖）
--------------------------------------------------------------------------------
  [B] 镜像分支的语义动机: 为何 slot ∈ {6,8,0xfa,0xf8} 需向 i+2 复制一条 C2 记录，
      且「6/8 用 p1 反向门、0xfa/0xf8 用 p2 正向门」— 疑与「同向相邻中枢段」有关。
  [C] newSlotRaw 编码 {9, 2, 0xF7, 0xFE} 的含义（归一后均为槽 1；原始字节存 C2.slotB）。
  [C] 本批未做动态验证（frida 待用户在场）。
