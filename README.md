# clone-ronglide

融立德（缠中说禅）交易软件 —— 「无脑买入线段」指标核心算法逆向分析。

本仓库记录了从**明文字段定位**到**核心算法反编译**的完整研究过程，目标指标为菜单
「缠论 → 无脑买入线段」（命令号 `CmdId=4431`）。

## 研究目标

| 层级 | 内容 | 载体 |
| --- | --- | --- |
| ① 菜单入口 | `CmdId=4431` | `Sys/Mainmenu.xml` |
| ② 公式明文 | 公式 `WNMR_线段` | `TAF/SysTA.taf`（GBK 编码） |
| ③ 核心算法 | `WNMRNEW` / `WNMRPRINEW` | `TAFLib.dll`（机器码） |

## 核心结论

### 1. 「无脑」算法本质

> 相邻两段的价格区间 **[low_a, high_a] 与 [low_b, high_b] 完全不重叠**，即
> `high_a < low_b` 或 `high_b < low_a`，即在区间边界直接标记买/卖点 ——
> 无需中枢确认、无需背驰、无需 MACD 验证。

### 2. 关键数据结构（级别对象，步长 `0xA0` = 160 字节）

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| `+0x00` | int | 序号（自身索引） |
| `+0x04` | int | 索引 A（前一顶点）**★卖出组取此字段** |
| `+0x08` | int | 索引 B（后一顶点）**★买入组取此字段** |
| `+0x0C` | float | **LOW**（笔端点低点价）★卖出价源 |
| `+0x10` | float | **HIGH**（笔端点高点价）★买入价源 |
| `+0x14` | int | **分型方向选择器**（1=取后继底 / -1=取前驱顶） |
| `+0x20` | int | **方向标志**（1=上涨 / -1=下跌 / 0=未定） |
| `+0x88` | int | 分型标志（1=顶 / -1=底） |
| `+0x8C` | int | 信号标志（0/1/-1） |
| `+0x90` | int | **状态码（1–6）** |
| `+0x94` | float | **该点实际价格** |
| `+0x98` | int | 特殊标志 |

### 2b. 容器与迭代器模型（第六批）

级别对象存放在 **MSVC 安全 STL 的 `std::vector<LevelObj>`** 中：

```c
typedef struct VectorLevelObj {   /* 16 字节 */
    void*     _Myproxy;   /* +0x00  分配器代理 */
    LevelObj* _Myfirst;   /* +0x04  首元素 */
    LevelObj* _Mylast;    /* +0x08  末元素后一位置（迭代终点） */
    LevelObj* _Myend;     /* +0x0C  容量末尾 */
} VectorLevelObj;

typedef struct CheckedIter {      /* 8 字节（受检迭代器） */
    VectorLevelObj* _Mycont;  /* +0x00  所属容器（越界校验用） */
    LevelObj*       _Myptr;   /* +0x04  当前元素 */
} CheckedIter;
```

- `sub_1003f0d0(vec, out, n)` = **`vec.begin() + n`**（n 原样使用，无 ±1 调整）
- `sub_1003d720` = **`it++`**（`_Myptr += 0xA0`）；`sub_1003d750` = **`it--`**（`-= 0xA0`）
- `sub_1003f150` = **按值深拷贝容器（快照）**，非"取首元素"
- 安全 STL 指纹：`_invalid_parameter_noinfo`（`ds:[1006F194h]`）

> `sizeof(LevelObj) = 0xA0` 由**四条独立途径**互证：魔数 `÷160`、步进立即数 `0xA0`、
> `rep movsd` 计数 `0x28`、分配 `count×160`。

### 2c. 容器结构修正（第七批）

上述 vector **并非独立对象**，而是**容器类 W 的一个内嵌成员**。W 含 **8 个 16 字节的 vector 成员**：

```c
typedef struct VectorMember {   /* 16 字节 */
    uint32_t hdr;               /* 记录起始，构造器不零化 */
    void*    _Myfirst;          /* 记录 +0x04 */
    void*    _Mylast;           /* 记录 +0x08 */
    void*    _Myend;            /* 记录 +0x0C */
} VectorMember;

typedef struct AnalyzerCtx {    /* W，尺寸 ≥ 0xBC */
    VectorMember m[8];          /* +0x00,+0x10,...,+0x70 */
    float        f_0x80;        /* +0x80 = 0.0f */
    uint32_t     u_0x84;
    /* +0x88/+0x8C/+0x90 不在构造器零化列表 */
    uint32_t     u_0x94 ... u_0xB8;
} AnalyzerCtx;
```

- `sub_1003d910` = **W 的构造函数**（零化 8 个成员的 3 个指针）
- `sub_1003d9e0` = **W 的析构函数**（释放 `+0x74/+0x64/+0x54/…`）
- 引擎遍历的是 **`W->m[4]`**（数据指针 `+0x44`/`+0x48`）；`[esp+43Ch]` = `W+0x40`
- 与 `sizeof(LevelObj)=0xA0` **无矛盾**：W 是容器，元素才是 0xA0

> ⚠️ **源报告缺陷**：`re-TAFLib.md` 的 `[esp+X]` 是**当前-esp 相对**记法，
> 同一文本偏移在不同代码点指向**不同变量**（实测 `[esp+40h]` → 帧偏移 −1016/−976/−808）。
> **跨代码点比对栈槽前必须先做栈跟踪换算。**

### 3. 状态码矩阵（`+0x90`）—— 共 **24 处**写入点 = 4 组算法实例

| 码 | 价格源 | 语义 | 实例①地址 |
| --- | --- | --- | --- |
| 1 | `+0x10` HIGH | 上涨结构起点 | `0x1005a1fa` |
| **2** | `+0x10` HIGH | **买入价** | `0x1005a243` |
| 3 | `+0x10` HIGH | **止损价** | `0x1005a2ca` |
| 4 | `+0x0C` LOW | 下跌结构起点 | `0x10057c20` |
| **5** | `+0x0C` LOW | **卖出价** | `0x10057c69` |
| 6 | `+0x0C` LOW | **止盈价** | `0x10057cf0` |

规律：**买入组全用 HIGH(`+0x10`)，卖出组全用 LOW(`+0x0C`)；
买入组取「后一顶点」(`+0x08`)，卖出组取「前一顶点」(`+0x04`)。**

完整 24 处写入点构成 **4 个算法实例**（`sub_10056190` 是同一模板的 4 次内联展开）：

| 实例 | 卖出段(4/5/6) | 买入段(1/2/3) |
| --- | --- | --- |
| ① | `0x10057c20` / `0x10057c69` / `0x10057cf0` | `0x1005a1fa` / `0x1005a243` / `0x1005a2ca` |
| ② | `0x10058336` / `0x1005837f` / `0x10058406` | `0x1005a85c` / `0x1005a8a5` / `0x1005a92c` |
| ③ | `0x1005b737` / `0x1005b780` / `0x1005b807` | `0x1005bcd4` / `0x1005bd1d` / `0x1005bda4` |
| ④ | `0x1005c47a` / `0x1005c4c3` / `0x1005c54a` | `0x1005cae3` / `0x1005cb2c` / `0x1005cbb3` |

### 4. 浮点判定规则（x87 三掩码）

| 掩码 | 分支 | 次数 | 语义 |
| --- | --- | --- | --- |
| `test ah,5` | `jp` | 49 | **ST0 == ST1**（判等） |
| `test ah,41h` | `jne` | 39 | **ST0 > ST1**（判大） |
| `test ah,1` | `jne` | 12 | **ST0 < ST1**（判小） |

合计 147 次浮点判定，其中 `test ah,41h`(69次) 出现最多 —— 引擎主体是
**区间高低点的大小比较**，而非仅判等。

### 5. 重要修正

- **不存在「止损/止盈比例」**：`sub_10056190` 含 145 次 `fcompp` 比较，但
  `fadd/fsub/fmul/fdiv = 0`。价格全部直接取自区间高低点，非按百分比计算。
- **「无脑」精确条件**：不是简单的 `≠`，而是**严格不等重叠**（`>` / `<` 判定）。

## 分析方法

- **公式明文提取**：Python 读取 `SysTA.taf` 二进制，`decode('gbk','ignore')` 后检索公式名
- **PE 解析**：手动解析节表（VA→文件偏移：`BASE=0x10000000`），提取 `.rdata` 常量
- **反编译**：基于 IDA 风格函数级反汇编报告，逐段还原 + x87 标志位精确解码
- **指令统计**：Python 脚本对反汇编做掩码-分支配对、操作数-字段组合频次分析

## 未完成事项

- **`+0x04`/`+0x08` 的基数未定**：`+0x00` 明确 1 基，但 `sub_1003f0d0` 对 `+0x04`/`+0x08` 无减 1。
  已穷举确认这两个字段在 0xA0 元素上**无字段级写入**（详见 docs/07 §7）。
- 0xA0 元素的构造函数未定位（W 的构造函数已定位，见 §2c）
- `sub_1003F170`（11,169 条指令）需用**递归下降**重扫（线性扫描可能漏检）
- 同族引擎 `sub_10060c00` 尚未逐条展开
- x64dbg 动态验证（断点 `0x1005a1fa`）—— 需在本机执行
